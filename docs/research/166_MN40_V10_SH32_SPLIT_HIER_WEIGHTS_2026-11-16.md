# ModelNet40 分类 V10 的 HIER 分项权重消融

用户批准先在 8001 GPU 0 跑样本项渐增组，再让 8001 GPU 2 的样本项组等待空闲。两组均以 TS35 为直接对照，沿用 B05、自然 Shuffle、batch32、seed 4780、A1、Ks20/Kp20、T50、512 个代理和固定壳。单卡从头训练 300 轮，每轮 307 次更新，共 92,100 次。使用官方 train 9,840 和 test 2,468，每轮评估完整测试集，按三位小数测试 OA 严格上升更新 best，平局保留较早轮，AA 取同轮。

| 编号 | 样本项系数 | 代理内部项系数 | 回答的问题 |
| --- | --- | --- | --- |
| TS35 | .5 | .5 | 已有完整对照 |
| TS45 | e1 为 0，线性升至 e51 的 .5，之后固定 | .5 | 逐步引入样本关系能否提高分类峰值 |
| TS46 | .5 | 0 | 代理内部项对分类的影响 |

TS46 的代理仍由样本项通过 A1 更新。两组都按 TS35 的调用顺序计算两个 HIER 项，系数为 0 的项仍保留损失及三元组统计。主网、优化器、候选池和随机种子沿用 TS35。两组各自核验权重日程、数据文件指纹、初值、首批输入和首轮 307 次更新。
