# V9角度与有效优化尺度：独立数学审查

日期：2026-10-22。范围：既有文档、官方固定源码及CPU双精度数学核验；没有GPU、SSH、权重前向或训练。这里的中心是理想双曲几何中的绝对minimax中心，不能直接解释成HIER必须学到的代理。

## 1. 两点中点与初始化的精确阈值

记曲率为−c，q=√c，whole原点深度为H。将两个单位方向u1/u2放到单位曲率缩放后的双曲面上：

`X_i = (cosh(qH), sinh(qH) u_i)`。

测地中点等于`X1+X2`的Lorentz归一化，空间分量/时间分量比得到

`tanh(q r_mid) = tanh(qH) cos(theta/2)`。

所以

`r_mid = atanh[tanh(qH) cos(theta/2)] / q`。

在c=.1、H=4.6时：

| 两whole夹角 | 中点深度 |
|---:|---:|
| 0° | 4.600000000 |
| 5° | 4.586291633 |
| 10° | 4.545818971 |
| 20° | 4.392918767 |
| 30° | 4.164984884 |
| 40° | 3.889129115 |
| 60° | 3.277566866 |
| 90° | 2.365613073 |
| 120° | 1.526038380 |
| 160° | 0.496385971 |
| 180° | 0 |

`r_mid=4.14`的夹角阈值为30.966654421°。该数值支持“足够窄的局部群体，其绝对中心在初始典型深度之外”，不支持“所有代理应外移”或“中点比初始化深所以应该撞cap”。任意非零夹角的理想两点中点仍严格浅于4.6。

V9初始化是高斯尺度0.9，不是所有代理深度精确4.14。首次越cap还取决于具体代理的初始余量、实际方向与实际Adam步幅。报告71所记录第1步全体平均模长下降但19个代理越cap，与此相容。

## 2. 三点最小包围球中心的精确算法

对于同壳的三个单位方向u_i，定义单纯形中的最小范数组合：

`v = sum(alpha_i u_i), alpha_i>=0, sum(alpha_i)=1`，使`||v||`最小；令`t=||v||`。

若t>0，最小包围球中心的方向为`v/t`，深度为

`r_3 = atanh[t tanh(qH)] / q`。

若t=0，最优中心为原点。证明分两步：

1. 原点到凸包的Euclidean投影满足`u_i·v>=||v||²`。故方向v/t所能保证的最小方向余弦至少为t。
2. 对任意单位方向w，`min_i w·u_i <= w·v <= ||v||=t`。因此该方向达到了最大的最差方向余弦。固定该余弦t，再最小化双曲距离余弦`cosh(qH)cosh(qr)-t sinh(qH)sinh(qr)`，对r求导得到上述深度。

三个方向的Gram矩阵`G_ij=u_i·u_j`把问题写为`min alpha^T G alpha`。枚举3个顶点、3条边中点（各方向为单位向量，边上极小值必为中点）、全三点面上的KKT解，即得精确解。满秩时面上候选为

`alpha = G^{-1} 1 / (1^T G^{-1} 1)`，只在所有权重非负时保留。

实现使用增广KKT矩阵以兼容Gram奇异但仿射独立的情况；退化系统用最小二乘，边界解由边/顶点枚举覆盖。`projection_residual`独立检查上述投影证书。

由最小球冠的包含关系，同壳三点中心深度不高于其中任意两点中点深度。但不能用三个pair深度的均值代替三点中心；一般也不能仅用跨类平均夹角推断它。三个逐对夹角的完整Gram矩阵足够确定理想三点中心，单个角度平均不够。

## 3. 为什么它不能直接预测HIER代理半径

本地官方固定参考`D:/Hycore/.codex-local/references/HIER-CVPR23/hier/losses.py`中的`compute_gHHC`（约第43–60行）与现用三hinge一致。minimax用于选择有限候选；优化目标是三个相对距离hinge，不是绝对最小包围球半径。

另外，代理共享于不同pair/triple，两个角色的Gumbel抽样相互独立，proxy项还让代理兼任端点。完整straight-through梯度包含改变被选概率的路径。因此即使每个pair/triple的理想中心都浅于whole，也不能推出HIER所有代理都应回到该中心深度。

“壳上存在零hinge解”说明缺少必然的内缩恢复力；它不是当前模型每个真实三元组已零损失的证据。越cap后当前raw径向梯度受到映射压制，又为不返回提供第二个条件。实际持续向外位移仍需由m/v、预条件与参数有限步核算，不能单由该可行解推导出来。

## 4. 对角度审查的判读要求

- 对每个真实样本对先计算角度和中点深度，再汇总均值、分位数、CDF及`r_mid>4.14`比例；不能先求平均余弦、acos后再代入非线性公式。
- 同类样本对、跨类样本对、类别中心夹角、实际挖掘i/j/k角度是不同量。首先分别报告前两者，再补训练挖掘关系；随机异类对不能代替hard/reciprocal负例。
- 对比原HIER Cars与V9时以共同c=.1、H=4.6的HIER视图做理想中心计算。V9原生c1/raw深浅分散可另外记录，不混到该估算中。
- 原Cars与ModelNet40任务、类别语义、维度、监督与采样不同，横向差异仅是分布对照。不能把某数据集的均值变化解释为只由“分类vs检索”造成。
- best/终点可回答“当前分布是否更聚集”，不能单独回答“首次撞cap时为什么外移”；若现成早期缓存存在，应检查e0/e1/e5等，而不需要为角度统计重训。
- 方向分布描述只涉及sample项端点；proxy项曾在早期full-ST外移中占明显作用，sample角度对照不能解释它的全部机制。
- 代理相对whole/相对理想中心的方向对齐程度同样关键。窄类内群体并不使随机初始代理自动沿其中心方向，不能只依据类别内角度声称吸引力向外。

## 5. “移植后力度太大”的可检验含义

该假说有意义，但应拆为原始梯度大、Adam有效步幅大、相对径向余量大三件事。已有57/71报告甚至出现V9当前梯度比原版小而实际Adam步幅更大的情况，故不宜表述为梯度爆炸。

- 角度更窄会使理想pair中心更深，改变直接吸引的径向符号、hinge激活和候选竞争。
- 同一tau=.1在不同的候选代价差分布下，softmax熵和路由导数大小不同。重点是cost gap/tau，而不是同一个tau数字。非常饱和时导数可能小，临界竞争区也可能变大。
- 同一margin=.1改变的首先是hinge激活集合；固定一条已激活hinge的直接距离梯度不因margin增大而线性增大。
- 同一lambda=.5改变梯度尺度，但对于只被HIER更新的AdamW代理，全历史等比例缩放时m和sqrt(v)一起缩放，步幅不同比缩放；eps主导时缩放才更直接。
- LR、D、beta、WD、eps以及初始半径余量共同决定有效步幅。fresh Adam在eps可忽略时的向量位移上界量级为eta sqrt(D)，不是径向位移。V9 .01×sqrt(256)=.16；参考Cars .005×sqrt(512)≈.113，仅用于尺度提示，不能作实际位移替代。
- batch损失使用mean，不应把batch数量差直接当成乘法增强；类别组成、有效hinge比例、碰撞比例与随机噪声才影响实际梯度。

最有信息的数字是每坐标`sqrt(vhat)/eps`、真实位移/剩余raw半径、径向与切向位移、full-ST/固定选择/routing分项、hinge激活与候选代价差。它们能把分布压力与数值步幅分开。
