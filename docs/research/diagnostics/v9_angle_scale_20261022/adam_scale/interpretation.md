# AdamW、HIER权重与精度：审查说明

本说明只读已有代码与状态；固定状态干预只更新CPU私有副本，不训练编码器或代理生产状态。

## λ=.5并不等于代理AdamW步长=.5倍

记HIER外权重为λ，weight decay系数另记为ρ，避免二者混淆。V9代理只接收HIER梯度，base CE/intra不直接更新这些代理。若g表示带λ的梯度：

\[
m_t=\beta_1m_{t-1}+(1-\beta_1)g_t,\quad
v_t=\beta_2v_{t-1}+(1-\beta_2)g_t^2,
\]
\[
\Delta p=-\eta\frac{\widehat m_t}{\sqrt{\widehat v_t}+\epsilon}-\eta\rho p.
\]

若在同一假定梯度历史上将λ缩放s倍，则m缩放s、v缩放s²，梯度更新项成为：

\[
-\eta\frac{\widehat m_t}{\sqrt{\widehat v_t}+\epsilon/s}.
\]

因此，当分母远大于eps时，统一缩小正λ对代理实际步长的作用可能很小；当eps占主导时，λ缩小才接近同比缩小自适应更新。λ=0是关闭目标，不适用正s的约消。已经训练后的单步只改当前梯度，不会同时缩放旧m/v，也不能套用整段历史缩放结论。

共享编码器另有CE/intra，HIER权重会改变这些梯度的相对份额及方向；其RiemannianSGD不具有同样的Adam归一化约消。因此不能由代理侧分析推断λ对完整网络没有影响。

原版Cars与V9的HIER外权重均为.5；单独这个共同值不能解释二者差异。

## eps是分母的尺度阈值

eps改善数值稳定性，防止分母为零或过小；它不仅在恰好除零时生效。若sqrt(vhat)远小于eps，更新近似为-η*mhat/eps；提高eps会压低这类小梯度坐标的有效增益。它没有固定的内向或外向偏好，也不是径向恢复力。

相同m/v/g下，提高eps对各坐标衰减不同，可能改变更新方向；对原外移轨迹，衰减后固定向内的weight decay可能占优，所以总径向位移会变为向内。不能将这解释为eps新增了内推损失。

## 历史m是什么，为什么能与当前g方向不同

m是历史梯度的一阶指数滑动平均，属于动量机制；v是梯度平方的二阶滑动平均，提供逐坐标缩放。β1=.9时，k步前梯度的权重按.9^k衰减，半衰期约6.58步，100步前约2.66e-5；“历史m”不是第一步的力永久保留2000步。

旧梯度是在旧参数位置、旧候选选择和旧batch上产生的。它们与当前g方向可不同，当前g也可能已经转向。尤其方向旋转时，旧位置的切向量在当前位置未必切向。若g与旧p正交，p'=p-ηg，则g·p'=-η||g||²：相对新位置，继续沿旧下降方向走带有外向分量。

以当前u=p/||p||为参照，g·u>0表示普通梯度下降倾向内移，m·u<0则表示负m更新可能外移；实际Adam位移还须通过逐坐标分母计算，不能只看任一内积符号。报告71的“当前径向项近零而略内向”与“历史径向项主导外移”是同一步的分项核算，不矛盾。

## “FP16训练”需要更准确地写为AMP混合精度

原版HIER源码使用autocast和GradScaler，并显式写出`eps=1e-4 if args.use_fp16 else 1e-8`。源码没有说明作者选择这两个数的具体实验理由，因此不能声称已证明该差异专为防止FP16分母下溢。

实际Cars已有权重的代理参数、exp_avg与exp_avg_sq均为float32。V9保存的p/g/m/v也均为torch.float32。原版的use_fp16=True不表示代理参数和Adam状态以纯FP16保存；GradScaler在优化器更新前将梯度反缩放，不能把它当作额外有效学习率。

纯FP16算术中1e-8可舍入为0，这是一般数值风险，但不直接解释这份Cars权重，因为其Adam参数/状态为FP32。对当前比较，精度设置与eps变化是作者代码将两项绑定产生的配方差异，原则上可以独立设置FP32+eps1e-4。

## 真实配方比较

| 项目 | 原版Cars best | V9诊断/历史V9配置 |
| --- | --- | --- |
| 基础目标 | PA角度检索损失 | 双曲分类CE+intra |
| HIER外系数 | .5 | .5 |
| 层次代理维度/个数 | 512/512 | 256/512 |
| global batch | 180 | 64 |
| 参数/Adam状态dtype | FP32（训练启用AMP） | FP32 |
| eps | 1e-4 | 1e-8 |
| 初始代理LR | .005 | .01 |
| β1/β2、WD | .9/.999、.01 | .9/.999、.01 |
| 调度 | 每10轮乘.5，共100轮 | 300轮余弦，最低.0005 |
| best保存步数/LR | 1980/.0003125 | 不同阶段单独报告 |
| 代理裁剪梯度 | 配置clip_grad>0时源码按坐标截到±10 | 无代理梯度裁剪 |

原版Cars已保存状态的sqrt(vhat)坐标中位数5.9172e-6，99.9985%坐标小于其eps1e-4；该值读取旧v，不含下一步未知g，不是精确训练重放。它说明eps在这份实际状态中是主要分母尺度，不能忽略。

两者梯度绝对值、维度、batch和学习步数不能直接等价。降低batch会改变采样噪声和关系选择；本HIER按抽样数均值归一化，不能仅因64<180便说梯度必定放大180/64倍。更有意义的“力度”指标是实际位移相对raw模长、距cap余量和方向转动，而不是loss数值或梯度范数单项。
