## 问题与对照边界

MN40上HIER收益随组批及配方变化，较平衡MN20子集仍未消除SH/CB差异。本批更换为HyCoRe本来支持的真实扫描任务，检验**一套确定的HIER分支能否提高同批重训的原生HyCoRe**。SO-HIER−SO-H0为直接对照，两组共享数据、原网络初值、主支采样/增强/裁剪随机协议、预算、卡数和选模规则。

此处H0保留HyCoRe原有的两项whole–part目标，不是纯CE。新数据同时改变形态、背景、遮挡和类别集合，不能只凭两组判断类别不平衡的因果作用；单seed不能证明稳定普遍增益。论文中的HyCoRe分数只作历史量级参考。

## 两组共同的原生训练配方

PointMLP四级局部聚合，通道128→256→512→1024；全局max、1024→512投影，再经原生c1双曲嵌入512→256和双曲分类头256→15。part先、whole后，共用网络。主支无新增出口cap或GS，保留原生数值投影。

| 项目 | 实际固定值 |
| --- | --- |
| 增强 | 各轴scale[2/3,1.5]、平移[−.2,.2]、点序shuffle |
| whole／part | whole随机600–1024；part随机200至`floor((whole_K−1)/2)`，保留原helper返回k−1和part覆写whole别名的行为 |
| 基础目标 | CE标签平滑.2＋.01×对比项（margin4）＋.001×局部层次项（margin500/Npart） |
| 主优化器 | RiemannianSGD，LR .1→.001，300轮cosine，momentum.9，WD1e−4；原网参数总梯度范数裁剪1 |
| loader／BN | train32、shuffle/drop_last；test32、shuffle/drop_last=False；workers8；每步part与whole各一次训练前向 |
| 初始化／预算 | 相同原网初值，从头300轮；无teacher、无续训权重、无短测权重继承 |
| 选模 | 官方完整train训练、每轮完整test，三位小数OA严格升高选best、同分取早轮；不早停，AA报best同轮，另报e300及末10均值/SD |

seed由发布入口默认12共同覆盖为项目约定4780；这是明确的成对设置，不称默认seed复现。保留发布实现的`cudnn.benchmark=True`及原生非确定性设置，不承诺跨运行或跨设备整程参数逐位一致。

## 唯一开启的HIER分支

从whole的`model.emb`后、分类头前读取μ：`logmap0(c1) → 切空间cap2.3 → expmap(c=.1) → 分支GS`。**不使用固定4.6壳**，允许上界内不同深度；原生主支仍使用原μ。无额外编码器或额外batch，样本锚点与候选均来自当前SH32，不使用队列。

512×256可训练自由代理，高斯初始化缩放.9、独立cap2.3/GS；A1 AdamW LR .005→.0005、eps1e−4、betas(.9,.999)、WD.01、300轮cosine。Ks20/Kp20、每锚T50、margin/τ=.1、样本项与代理内部项系数各.5，W0。保留self-negative修正，关系挖掘和Gumbel使用独立派生随机流。代理不纳入原网norm1裁剪，每步主优化器和代理优化器各更新一次。
