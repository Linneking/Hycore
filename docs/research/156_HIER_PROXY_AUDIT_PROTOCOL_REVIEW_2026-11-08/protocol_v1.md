# HIER 代理审查 v1.0

2026-11-10 通过。用于诊断原 HIER 及 HyCoRe 加 HIER 的代理使用、距离目标和几何。依据 157 号对 CUB、Cars、SOP 三份 best 的试审。参考权重与旧口径见[审查沿革](report.md)。

审查开头记清权重、轮次、样本池、回放随机种子和 HIER 实际使用的嵌入。按各实验自己的抽样和代表选择规则回放完整一轮，期间固定权重。记录总批数、样本关系数和代理内部关系数。历史训练日志和确定性检查分别标注。不同数据集各走自己的一轮，覆盖率按各自的批数和采样来读。

| 主检查 | 固定输出 |
| --- | --- |
| **代理用得怎样** | 样本与代理内部各分两点代表、三点代表。统计每个角色实际用过多少个代理、用得最多的代理和前十名各占多少选择，以及角色之间有多少共同编号。主表用非碰撞关系，同表注明在仍有违反的关系中用过多少代理。每个角色的份额以该来源的非碰撞关系数为分母。 |
| **三条距离要求各达标多少** | 样本项和代理内部项分别报 `i` 更接近 A、`j` 更接近 A、`k` 更接近 B 的达标数和比例，按各实验实际距离余量计算。A 为两点代表、B 为三点代表。分母为 A、B 不同的关系数，两次选到同一代表的次数另记。按源代码保留端点重复规则并注明。三项联合达标数放补充。 |
| **代理在哪里，附近有什么** | 给样本和代理深度图，分开报告原参数超 cap 和前向贴壳。如果 HIER 输入经过等深处理，注明实际深度并与原生嵌入分列。用无增强的完整训练样本池和 HIER 实际使用的嵌入及距离做 top4，报去重覆盖、样本池大小和热点，按预先写好的规则选少量样例目测。 |

某类关系全碰撞时，非碰撞比例栏记为不适用，另报碰撞总数。top4 的热点份额以实际近邻位置总数为分母。

**按问题追加检查。** 遇到贴壳或位移异常，查梯度大小及径向、角向分量。要解释深度分层，在同一条关系内比较 A 与 B，注明近等深容差。达标率看似改善但仍有较大错误时，查未达标的平均差额。均匀使用等效数和长期角色稳定性留作补充。

**结论分别写。** 入选次数描述代理被怎样使用，top4 目测描述附近样本。主任务收益另外用匹配训练配置、卡数和评估规则的 HIER-on/off 比较，原 HIER 用同一未见类检索评估。关闭组没有训练中的 HIER 代理，代理审查栏标为不适用。独立形态检验暂留后续。代理均匀使用、固定分层或全部回到 cap 内均不设为通过门槛。

**当前资料的限制。** 旧的完整随机回放保存了代理选择与三项联合达标数。三项逐一达标数来自另一次确定性复核。后续回放直接按批保存三个达标计数和分母，再汇总整轮。v1.0 固定审查口径，试审资料仍按实际来源解读。
