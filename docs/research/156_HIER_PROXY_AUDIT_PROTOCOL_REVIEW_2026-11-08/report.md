## 1. 先核查三份参考模型有没有达到论文表现

比较对象统一为ResNet50、512维、Proxy Anchor主任务加HIER。论文Table 1对应R@1为CUB70.1%、Cars88.2%、SOP80.2%。来源：[作者论文Table 1及§4.1–4.2](https://arxiv.org/html/2212.14258v3#S4)。不能拿ViT、DeiT、DINO或其他维度的结果比较。

| --- | ---: | ---: | ---: | ---: |
| CUB | 17 | 68.501013 | 70.1 | −1.598987 |
| Cars | 45 | 87.850467 | 88.2 | −0.349533 |
| SOP | 96 | 80.104790 | 80.2 | −0.095210 |

**结论：三组保存成绩均未达到论文表中的点估计，但SOP最接近，明显差距主要在CUB。** 不能因为SOP大量代理越cap，就认定收到的SOP权重损坏或主任务复现失败。当前也不能仅凭接近的检索成绩确认其代理已复现论文所述的语义层次。

证据来自既有loader manifest中三份checkpoint的`effective_args.best_recall`，并与原交接元数据对应；本轮又安全直接读取三份原始best及重算文件SHA，保存分数、epoch和哈希完全吻合。此前全部缓存另通过身份、映射及图像anchor核查，见[45](../45_ORIGINAL_HIER_BEST_GEOMETRY_AUDIT_2026-10-08.md)与[46](../46_ORIGINAL_HIER_SOP_MECHANISM_AND_ACTIVATION_2026-10-08.md)。上表为**保存成绩核验**；独立缓存复核另行列明。原始权重、manifest和路径保留在本机私有归档。

**独立缓存结果同样表明SOP检索接近论文，CUB差距最大。** 本轮未独立核验所有Recall@K、HIER-off增益、完整选模时间线或语义层次claim。

还需保留以下解释边界：

- 原评估是未见类eval池内检索、排除索引自身，以双曲距离计算Recall@K；不是代理反向top4，也不是训练集分类准确率。
- 保存配置均为PA、D512/c0.1、lambda2=.5；论文正文写HIER权重1。发布脚本与论文叙述需区别，不能把这批权重当作逐项完全等同论文配方的证明。
- Cars的原两rank评估采样存在padding：8131个对象可形成8132个评估槽。今后缓存去重重算时应并列给出原评估与去重结果，不强求两种分母逐位相同。
- 只靠三份HIER-on权重不能核实“HIER相对同配方PA有多少增益”；需要对应HIER-off基线。检索表现接近论文与层次语义兑现是两条独立证据。
- 原交接声明修复官方无条件覆盖`best_recall`并新增按R@1保存best；训练本地diff及逐轮日志未随本机包交付。因此不能仅从保存字段独立验证完整best选择时间线。该缺口同样适用于三组，不是SOP特有问题。
- 原HIER语义分析还展示了CUB/Cars的超类亲和和近邻外观共性，见[作者项目页](https://cvlab.postech.ac.kr/research/HIER/)。若要将本批权重作为“形态层次成功正例”，还需在这批权重上核验对应语义现象。

参考使用方式：SOP保留为“检索表现接近论文、但cap和方向热点显著”的机制参照；Cars作为接近论文的另一种状态参照；CUB保留但标记成绩差距，不能直接称为已达到论文水平的正例。不因某组几何不符合预想而事后剔除。

## 2. “512个正hinge祖先”究竟是什么意思

46包含固定best缓存回放和真实图像增强回放。二者均保持网络/BN/代理不变，**没有optimizer更新**。

1. 按各自源式采样回放一轮长度：CUB32批、Cars44批、SOP330批。
2. 对sample pair和sample triple分别计数：在整个窗口内，代理至少一次被hard选择作祖先，且A≠B、该关系三个hinge之和>0。每个角色的这类代理并集均为512。
3. 梯度只检查前2批：按完整ST路径，**前2批至少一批**分项参数梯度范数>1e−8的代理并集为512。该阈值为当次FP32探针口径，不是普遍训练充分标准。

因此不能改写为“每批512个”“历史每轮512个都有效更新”“512个都训练好了”。它只说明：这份best在所查条件下，有广泛的样本祖先参与及梯度响应，不支持把检索热点简单解释成大片代理完全收不到信号。

另外，正hinge表示仍存在需要优化的距离违反；零梯度既可能来自缺少信号，也可能因为目标已满足。必须把选择、非碰撞、正hinge、梯度和实际更新分别看。

## 3. 保留：六项基本审查

权重/缓存/对象身份与映射复核是所有项目的前置验收，不另算效果分数。

| 项目 | 固定输出 | 如何解释 |
| --- | --- | --- |
| **A. 几何状态** | 原生whole、HIER实际输入视图、代理各自深度分位/直方图/ECDF；raw越cap与前向贴cap；代理方向集中度R | 描述位置和可用自由度。cap、双峰和集中度均不单独判训练好坏 |
| **B. 目标兑现** | sample/proxy分别给三个hinge违反量、三项联合满足率、碰撞和self-k；全部及非碰撞两种分母；祖先等于端点另列 | 判断目标是否被满足。不能把碰撞归零当满足，也不能以正hinge多表示训练更好 |
| **C. 参与与使用分布** | sample pair/triple、proxy pair/triple、内部i/j/k分开；全部选择/非碰撞/正hinge；不同代理数、频率、熵有效数及头部份额；各分项并集 | 回答哪些代理参与什么目标，以及集中程度。不得只报一个总活跃率 |
| **D. 梯度与移动** | 同draw分项full-ST参数梯度范数与径向/角向分量，覆盖与分布；有真实日志或完整状态时给实际更新、深度变化与转角 | 反向响应和优化器位移分开。没有状态的旧权重标缺失，不伪造AdamW轨迹；不只查hard选中的代理 |
| **E. 同关系内的祖先作用** | 同一ijk的A/B距离、h(A)−h(B)、各端点−祖先深度差；近等深/正序/逆序；S/C/T及内部关系分开，角色交集另列 | 保留pair/triple相对作用。径向关系是描述量，不能以两组边际中位数相减替代，也不要求固定两个代理池 |
| **F. 反向检索与方向结构** | 全代理及各参与子集的top4覆盖/槽位归一/最大曝光/类别纯度；代理最近类夹角及代表类对/方向分布；固定规则选展示卡 | 保留覆盖与角度读数。top4不是训练后代，512×4仅2048槽；热点少、纯度高或接近类中心都不单独证明形态结构 |

每份结果用“已核验机制”“几何观察”“待解释现象”“独立效果”表述，不把六项加权成一个训练质量总分。

## 4. 新增为固定要求：三项

这里“新增”指纳入每次审查的前置/输出规范，部分方法在历史诊断中已经用过。

### N1. 原HIER参考资格与效应分开核验

先给参考权重的任务表现、论文匹配设置、数据/评估协议差异、保存成绩还是独立重算。检索表现资格和代理语义有效性分别注明。不能先默认“拿到的原版就是所有理想现象的成功标准”，也不能只因SOP贴cap将其剔除。

### N2. 以关系事件定义角色，允许代理身份变化

最小记录单位为`(分项, 时间窗, i,j,k, pair祖先A, triple祖先B, 碰撞, 三项hinge)`，代理ID只用于追踪同一参数。

同一ID可以在不同关系/时间承担pair、triple、内部端点等多种角色。先比较同一关系内的作用，再汇总不同角色的频率和交集；跨时间给角色份额向量与转动/深度变化，**不以永久绑定某类或某层为目标**。最近类角度继续作为当前关系的辅助读数，不要求每个ID始终靠近同一类。

### N3. 对齐抽样机会，并标注证据类型

自然一轮保持原配方，另按共同合法关系预算绘制累计使用覆盖曲线；同时报告总draw、非碰撞和正hinge数量。频率报告份额/每固定关系数，梯度覆盖报告实际探针batch数及阈值。

先固定选择方式（真实hard-Gumbel或确定性minimax）、K、候选数、self-k规则、距离实现/精度、margin、tau及HIER输入视图，再做同口径比较。**96确定性样本祖先291，不能直接与46源式随机回放512比较优劣。**

真实训练日志、best条件无更新回放、确定性几何读出分栏。统一预算读出与各自原配方读出均保留，避免为统一审查而隐去训练规则差异。具体预算数与统一运行入口留待实施方案确定，不将尚未执行的统一校准写成已有结果。

## 5. 删去作为通过/不通过标准的假设

| 删去的硬要求或推断 | 替代方式 |
| --- | --- |
| 所有代理必须回cap内；必须形成明显双峰/两层 | 保留分布与cap状态，结合分项梯度和目标兑现解释 |
| pair/triple必须两个互斥集合；同ID角色应长期固定 | 每条关系内比较，并报告角色份额/交叠/时间变化 |
| 所有祖先都必须严格浅于端点，才算HIER训练有效 | 原距离hinge与径向次序分开；额外径向目标按其自身设计单独验收 |
| 每个代理必须进入类别方向锥或接近某一类中心 | 角度分布及维度/类别组成匹配的随机参考；不要求永久类别绑定 |
| 代理必须均匀使用、无热点，top4应覆盖全部样本 | 给频率有效数、曝光和容量上限；不设理想均匀门槛 |
| 未被hard选中等于死亡；有ST梯度等于已学好 | 分开祖先选择、端点参与、目标状态、梯度和实际更新 |
| 深代理必须纯类、浅代理必须多类 | 保留为“浅广深专”待检验假说，不作为普适合格线 |
| 纯类top4、二维图成树或分类提升足以证明语义层次 | 独立形态/语义证据及匹配主任务对照另列 |

删除的是硬门槛和不成立推断，不删除原始读数。类中心角、cap、热点和深度次序仍会输出。

## 6. 改为异常时追加

- **热点/方向集中：** whole等深、代理整体旋转、去公共方向、同半径随机方向；有效秩/光谱详细分析。
- **冷落代理：** 同ij最佳内外候选账单，只换方向/深度的冻结反事实，e0→早期→best同ID机会追踪。
- **不移动、撞cap或目标失败：** 完整AdamW更新重构、m/v/WD归因、direct与ST分解、固定状态eps/LR对照；检查是否存在其他可行祖先候选。
- **增强/BN敏感：** 区分同噪声复现、换噪声、换增强和换分组条件，再查关系及梯度变化。
- **PartHier：** 真实part尺度链、队列曝光和候选来源为专用扩展；不并入自由代理的通用达标条件。

## 7. 成效验证单列，保留且加强

基本六项能回答训练和几何状态；若要宣称“有意义层次”，必须另有独立形态/语义证据。CUB可用已有属性等独立信息，Cars视角等需真实标注或明确的盲审规则；点云继续使用原尺度与去尺度Chamfer、固定对象及匹配HIER-off对照。不存在对应信号时写“未验证”，不能让类别纯度替代。

主任务表现另给匹配设置的HIER-on/off结果。主任务好不自动证明代理语义成立，结构指标好也不自动证明分类有收益。跨数据集不强求完全同一种形态信号，但每个“成功现象”都应注明其参照模型是否真的表达了该现象。

## 8. 本轮结论

保留六项基本审查；新增参考资格、动态角色和机会对齐三项固定规范；删除八类硬门槛；高成本机制拆解改为异常追加。SOP目前继续保留参照资格，不能用几何形态差异推断权重失效；CUB的保存成绩与论文差距较大，需单独标记。
