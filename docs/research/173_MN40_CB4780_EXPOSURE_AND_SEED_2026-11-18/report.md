# CB4780 是否偏爱某些对象：TS06/TS30 审查补充

2026-11-18。承接[171 原审查](../171_MN40_TS06_TS30_SAMPLING_ERROR_AUDIT_2026-11-18/report.md)，只补查类内频次、错误尾部及早期 seed22 记录。使用已有抽样实测和冻结预测，另做 CPU 抽样模拟；没有新增训练、推理或梯度审查。

**当前最有把握的结论：CB 改变了类别权重；尚未发现 seed4780 带来异常、持续的类内 ID 偏好。低频对象在 best 的局部训练错误中有弱信号，主要值得留意 dresser，但还不能解释相应测试错误。HIER 的收益应限定到具体配方和指标，不能概括成“CB/CY 有效、SH 无效”。**

## 1. 31–820 主要是跨类别差异

完整 300 轮最少的 31 次来自 chair，最多的 820 次来自 bowl，分别有 889、64 个训练对象。CB 每步从 40 类均匀选 16 类，各抽 2 次，所以一个大小为 n 的类别，每对象全程期望次数为 `300×200×(16/40)×2/n = 48000/n`。

因此，小类每个对象被更多使用是组批规则本身的结果。实测 chair 每对象平均 54.35 次，bowl 为 744 次；这不是同类某个对象比另一个多抽了 26 倍。次数也不等同于梯度大小。

下面才是与 best 错误对应的**类内**范围，全部截止 TS30 best e262；不是完整 300 轮。

| 类别 | 实际最少 / 平均 / 最多 | 均匀抽样时“全类最少次数”的 95% 范围 | “全类最多次数”的 95% 范围 | 测试净 SH 优势 |
| --- | ---: | ---: | ---: | ---: |
| table | 76 / 106.46 / 133 | 69–83 | 132–148 | +13 个 |
| dresser | 169 / 210.11 / 265 | 159–180 | 241–265 | +6 个 |
| vase | 60 / 88.82 / 114 | 55–67 | 112–127 | +6 个 |

这些区间是对各类实际抽样总次数固定后，均匀有放回抽样 4,000 次得到的**极值分布**，不是每个对象的置信区间。table、vase 没有显示异常分散；dresser 的整体次数分散程度约为均匀抽样预期的 1.25 倍，原始 p=.011，但在 40 类×best/e300 共 80 项校正后 q=.313。80 项中没有 q<.05 的结果；这不证明频次差无害。

## 3. seed4780 有持续的 ID 偏好吗

- 把 300 轮拆为三个 100 轮，按类内频次排名。前/中、前/后、中/后的相关分别为 **.0099、−.0015、−.0098**，接近零。三段都在高频尾的对象 13 个，独立随机排名预期约 9.34 个；低频尾同为 13 个，预期约 9.96 个。没有把这些少量重合解释成持续偏好。
- 用原采样器重放 12 个 seed：0、1、2、3、7、22、42、123、2026、2027、4780、4781；每个完整模拟 300×200 步。4780 在 e262/e300 的逐 ID 次数与原实测完全一致。
- 合并 40 类的次数分散比，12 个 seed 范围 **.963–1.028**，4780 为 **1.015**，没有表现成异常离群。这里比较的是采样分布，不是 OA，其他 seed 没有训练模型。

固定 seed 确实固定这次对象顺序和次数；它仍会产生有限抽样的不均。**可重放不等于每个对象等频，也不等于改变 seed 后 OA 不变。** 根 seed 还影响权重初始化、增强和裁剪，不能把历史 OA 差全部归给采样。

## 5. 现在能用来指导判断的三点

1. **CB 的首要已知变化是类别重加权和训练供给预算，不是已证实的坏 seed。** table/desk 的训练总呈现比在各自 best 从 SH 的约 1.96 改为 CB 的 1.006。table 的额外错误主要转向 desk，与相对类权重变化相容；但 dresser/night_stand 本来训练对象数都为 200，仍存在净差，说明这一解释不能包办所有边界。不能由观察直接断言因果。
2. **HIER 的局部收益成立，按 batch 一刀切尚不成立。** CB32 TS30→TS23 的 best/e300/末10 OA 为 +.162/+.365/+.263 个百分点；CY64 TS13→TS14 为 +.486/+.486/+1.147。另一方面，CB32 TS30→TS32 的 best 上升但末段下降；新版 CB64 TS17 缺匹配 H0。SH32 的 B05 目前 best 未超过 TS06，但 TS44 相对 TS06 的 e300/末10提高 .567/.389；B17 的 SH 配对 TS39→TS40 也有 +.162/+.041/+.231。因此应说“特定 CB/CY 配方看到了收益，普通 B05 SH32 尚无峰值突破”。基底低、提升空间较大是合理假设，尚未与 HIER 对组批的适配性区分开。[配对总表](../V9%2610.md)
3. **CB best 多判对 123 个 clean 训练对象，只是拟合事实。** 它既不证明过拟合，也没有解释测试净差。当前优先保留类别权重变化、局部低频拟合和候选组织三个可区分的问题。已在训的 TS48/49 保持分类分支 SH 供给，只改变同历史窗口的候选选法，能更直接检验 HIER 的候选组织；本次不新增任务。
