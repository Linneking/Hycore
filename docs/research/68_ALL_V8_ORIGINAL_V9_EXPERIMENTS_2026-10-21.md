## 读表口径

- 所有准确率单位均为百分数。OA是总体正确率；AA是40类正确率均值。AA必须来自所列同一份best权重，不能取它自身的跨轮最大值。
- VS984：8856训练、984独立验证，按val OA及CE选best，表中的test是该val-best的2468 test成绩。它不是逐轮test最大值。
- TS：9840训练、无独立验证，每轮2468 test选best。表中val列为空，不用训练内984子集伪装独立验证。
- cap列指最终切空间模长上限，2.3对应约4.6的原点双曲深度，不是球坐标半径2.3。基础cap与代理cap分开说明。
- gamma/delta指Rhier阈值gamma/N与Rcontr阈值delta。所谓半margin为500/N、2；两个正则系数始终各0.01。
- 均衡64是双卡，每卡16类×2例、global32类×2例，普通local32 BN。旧组类内有放回；最新两组类内使用跨epoch保留游标的循环队列。
- 现代best轮次全部按已完成轮数（1起）列出。†历史原版保留原文件epoch=229（0起）元数据，其约等于第230轮，但不改写原文件编号。历史运行含早期resume，和从头R2分开。
- 原版修改入口仅保存到0.001个百分点的成绩，本表统一显示三位小数；其余源值在JSON保留完整精度。没有按2468人数反推并冒充未保存的精度。

## 共同优化器与HIER配置

| 项目 | 配置 |
| --- | --- |
| 主网络优化 | RiemannianSGD，lr0.1→0.005，300轮cosine，momentum0.9，weight decay0.0002，梯度范数clip1 |
| 基础损失 | CE + 0.01 Rcontr + 0.01 Rhier；label smoothing0.2 |
| 开启HIER的组 | 512代理、256维；K20、T50；margin0.1、tau0.1；总增量0.5×(Rsample+Rproxy)；第1步启用、无warmup；排除sample/proxy self-k |
| 代理初始化与映射 | 官方随机切向量，尺度2.3×0.9/sqrt(256)；c0.1、前向cap2.3、一次自身GS；无更新后参数投影 |
| 代理优化 | AdamW，lr0.01→0.0005，300轮cosine，betas0.9/0.999，eps1e-8，weight decay0.01 |
| 原版线加载与评估 | workers8、eval batch16、连续训练随机流；最新双卡配对新增独立采样/增强/crop/HIER随机流，保持两组匹配 |
| V8与原始V9加载与评估 | workers2、eval batch32；其版本化训练随机流不同于原版入口 |
| 数据前向 | part先whole后；共享普通BN；保留part覆盖whole的原始别名行为；不做voting |

这些共同项以各次正式配置为准。HIER分支与基础路径的差异不是换一个“总优化器”：它们的损失共同反向影响网络，代理由自己的AdamW更新。
