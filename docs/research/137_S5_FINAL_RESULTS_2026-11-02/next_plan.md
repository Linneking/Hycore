# 下一步无正则主支实验计划：S5-TAN-R0

2026-11-02。基于[最终结果](report.md)，供用户审阅。仅完成结果采集和计划，没有实现模型、排队或启动训练。本计划覆盖133中“尺度有效且R降低Class就先拆R”的机械延伸：终局R差距很小，且用户已明确优先无R主支。

## 理由与假设

S5-R0保持架构即可相对H0追回约4pp Class，说明监督与优化路径值得优先于新增容量研究。它相对DGCNN末20轮仍低2.061pp，其中motorbike贡献1.809pp；31/33/34在200轮在线训练记录及逐轮测试上TP均0。这是明确的剩余失败，而非只需细化边界。

旧131中H0的第一M后特征可线性读出bag4、rocket43、motorbike31，但33/34仍弱。故假设是“最后球坐标输出限制对部分失败有重要贡献”，不是预设只改最后层能解决所有部件，也不是认定原M初始化错误。

## 唯一新增生产候选

共同前缀：原DGCNN局部/全局/类别融合→Conv8/BN8/Leaky→Conv9/BN9/Leaky→U256；dp1/dp2删除。第一M为官方原生256→128。设其球内输出为μ128，最后层有效权重为W2_eff。

```text
已完成S5-R0：
U256 → EXP → M(256→128) → μ128
     → M(128→50)：proj(EXP₀(W2_eff · LOG₀(μ128))) → z50
     → CE(5z50, y)/5

拟议S5-TAN-R0：
U256 → EXP → M(256→128) → μ128
     → q50 = W2_eff · LOG₀(μ128)
     → CE(5q50, y)/5
```

保留最后层原_weight、_bias、weight属性的transport重参数化与初始化规则；不新建普通Linear、不加普通输出偏置/BN/激活。只改变最后层前向读出，合并检验最后EXP及数值投影的影响，不能进一步分别归因二者。

该候选保留双曲中间特征，最后输出是切空间实数分数，是新读出变体，不是原HyCoRe双M的原样实现。直接对已裁剪z50做LOG不能恢复投影前模长，不能代替上述q公式。

两种输出在固定参数时理论上沿相同方向，argmax相同；差别是概率、CE和梯度。只在训练后替换读出并不能按此理论立即提高准确率。

## 匹配控制

- 主比较：新S5-TAN-R0对已完成S5-R0；两组外层都保持CE(5score)/5。不能把新组改成CE(q)后仍称只改输出操作。
- 正则系数均0，自然shuffle32/drop_last、原2048点/k40、原增强和点序；不加类别重采样或部件权重。
- 同seed4780、原完整fresh初始化、同数据manifest；不从S5/H检查点续训，不从探针拟合头接着训。
- RSGD .1→.001、余弦200、momentum.9、WD1e-4、无全局梯度裁剪，200×437=87400更新。
- 保持BN每batch一次训练前传、原可观察的独立R采样RNG不影响训练流、原FP32与CE平滑关闭。
- 保持原test-best-Instance选模，评价时同时报告固定e200和末20轮，不改成test-best-Class。

这仍是历史开发协议下的候选筛选。以后确认最终方法时须采用匹配多seed及独立验证协议，不能把已在trainval训练过的val突然视为独立验证。

## 实施前与首轮验收

1. 新版本路径保留旧v6/v7/v9，核查共享参数、BN缓冲、最后层原始参数及有效W逐项一致，构造不额外消费训练随机流。
2. CPU数学契约：固定输入/权重时，两输出argmax一致；近并列和数值差异显式检查。数值有限，监督梯度符合新公式，R无活跃梯度。
3. 确认与S5原e0初始化、首批输入、数据流身份一致。保留manifest与每轮完整部件记录。
4. 沿用用户直接完整训练、不要GPU短测的要求。验收后只在完全空闲GPU正式fresh200；不打断其他任务，不覆盖任何结果。原训练源码工作区保持冻结。

## 记录与判断

- 主结果：全16类Class、Instance、逐类IoU，best-Instance同轮/e200/末20分别比较。
- 重点部件：31/33/34的训练在线及测试recall/precision/pooled IoU、预测点数、整部件漏检物体数；并保留全部50部件统计。
- 普通类别代价：bag/rocket/skateboard/earphone及其余11类，不只看motorbike。
- 末端q：模长、范围、标准差、softmax(5q)正确类概率、更新/梯度。q是实数分数，禁止把其模长解释为球边界、双曲距离或贴边率。
- 几何统计仍用于入球EXP、第一M输出μ；新旧输出margin单位不同，不能直接以margin绝对数较大判断优化更好。

预先区分结果：

|结果|允许的结论与下一步|
|---|---|
|31/33/34恢复且全Class提高，普通类代价可接受|支持末端球坐标读出限制了学习；随后匹配重复确认，不立即扩R网格|
|召回提高但precision低/全Class不提高|尚无任务收益，不能以部件被预测过宣布成功|
|Class提高但31/33/34仍0|读出对其他类有收益，核心motorbike问题仍未解决|
|恢复很弱或未恢复|仅约束此公式与配方；下一步先比较S5-R0自身U256/μ128可读性，再选第一M或Conv10非线性块对照|

最低比较为S5-R0固定e200 Class80.012%、末20均值79.996%；最终目标为DGCNN对应82.187%/82.057%，best口径另对照81.777%。提升需同时查看Instance与precision；一次seed不构成统计确认。
