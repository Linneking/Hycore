# S5-TAN研究线、恢复正则及HPCS启发

2026-11-03。用户明确授权只新增一条S5-TAN-R完整训练。本文件同时整理已验证结果与尚待验证的改进方向。执行状态见[execution.md](execution.md)。

## 共同网络与统一配置

普通DGCNN与本项目H系列的公共前端：

```text
XYZ → STN/三段EdgeConv → 局部x1/x2/x3，各64通道
局部192 → Conv6/BN6/Leaky → 全局max1024
物类one-hot16 → Conv7/BN7/Leaky → 64
全局与物类特征广播，拼接局部192 → 1280
→ Conv8(1280→256,bias=False) → BN8 → Leaky(.2) → T256
```

L9 = Conv9(256→256,bias=False)→BN9→Leaky(.2)。L10 = Conv10(256→128,bias=False)→BN10→Leaky(.2)。M是原HyCoRe完整MobiusLayer，包含原_weight/_bias和transport有效权重；内部没有BN、额外激活或dropout。

本轮对照全部沿用同一ShapeNetPart trainval14007/test2874、seed4780、2048点/k40、自然shuffle32/drop_last、200×437=87400更新。H系列为RSGD .1→.001余弦、momentum.9、WD1e-4、无总梯度裁剪；普通DGCNN为SGD，其协议差异不能归因于网络结构。保留历史test-best-Instance选模，同时报告固定e200和末20轮。

## 各组只展示公共前端之后的层

```text
DGCNN：
T256 → dp1(.5) → L9 → dp2(.5) → L10
     → Conv11(128→50,bias=False) → CE

H0/H/S5共有主支：
T256 → L9 → U256
     → EXP₀ → M(256→128) → μ128
     → M(128→50) → 球内坐标z50

H0：L = CE(z50)                         R关闭
H ：L = CE(z50) + .01Rcontr + .01Rhier  R开启
S5-R0：L = CE(5z50)/5                   R关闭
S5-R ：L = CE(5z50)/5 + .01Rcontr + .01Rhier

S5-TAN-R0与新S5-TAN-R共有主支：
T256 → L9 → U256
     → EXP₀ → M(256→128) → μ128
     → LOG₀ → W2_eff(128→50) → 实数分数q50

S5-TAN-R0：L = CE(5q50)/5
S5-TAN-R ：L = CE(5q50)/5 + .01Rcontr + .01Rhier
```

TAN保留最后层原参数与有效W，改变的是最后前向公式，没有新增普通偏置或BN/激活。q不作为球点，不能对其模长计算贴边率或双曲距离。

原正则分支位置在U256，而不是μ128或q50：

```text
U256 → 全部点欧氏均值whole_tangent → EXP₀ → whole
     → 特征近邻part的点均值part_tangent → EXP₀ → part
     → 同批异物类物体的part作为负例
     → Rcontr + Rhier
```

part大小200–600，层次margin=1000/Npart，对比margin=4，两个系数各.01。每个batch只编码一次、BN只更新一次。正则直接训练到U及其前序网络，不直接经过第一M或最后读出；它们仍由CE训练。

## HPCS提供的是另一种主支适配方式

已锁定官方HPCS c464387及其最直接结构参照VNN f3197e，详见[139源码审查](../139_HPCS_MAIN_BRANCH_AUDIT_2026-11-02/report.md)。HPCS使用VN-DGCNN旋转相关前端，其Conv8输入2299维；该差异属于前端表示，不能当双曲适配必需变化。将其前端单独压缩后：

```text
HPCS原VN基线尾部：
T256 → dp1 → L9 → dp2 → L10 → Conv11(128→50) → CE

HPCS（README d=32）：
T256 → dp1 → L9 → dp2 → L10
     → Conv11(128→32,bias=False) → 新增BN11
     → EXP₀ → z32
     → 与50个独立可训练类别向量计算归一化余弦分数
     → CosFace(s=2,m=.35)
```

等维配置无Möbius层。它保留欧氏判别尾部、令嵌入维度与类别数分离。点嵌入和类别向量均L2归一化，EXP的正径向缩放在理想余弦分数中抵消；主分类依赖方向。这个事实支持“将双曲表示与语义分数分开设计”的方向，但不是我们TAN或其正则收益的实验证据。

BN11是逐通道BN，不保证逐点向量远离球边界。HPCS的层次半径scale初值.001不是分类尺度或入球前缩放。它保留dropout也不能推翻我们自己的匹配消融。其层次聚类score/标签相关CosFace评估与我们的Class mIoU不同，不直接比较分数。

## 目前改进方向的优先级

1. **当前只执行TAN-R。** 保持已成功主支，测原正则增量；系数固定.01，不同时调尺度、margin或负例。R原损失标量与CE之比不等于梯度比，保留分项梯度监控，不能因R非零就称有益。
2. **分析现在的Instance差距。** 固定e200，table类别IoU比DGCNN低1.172pp，因为有848物体，对总体Instance差值贡献−.346pp；lamp贡献−.058pp。其他类有正贡献抵消，总Instance差−.212pp。下一次诊断应看table部件47/48/49和lamp的混淆、召回/精确率，再决定改监督或边界处理；不应默认沿用已解决的motorbike死部件假设。
3. **HPCS启发的可选读出。** 若需要进一步结构候选，可保留现有μ128、关闭R，单独测试归一化余弦类别读出与独立尺度，先margin=0，不同时改成32维或加入HypHC。将W2_eff归一化会抵消其某些径向缩放，原transport的_bias可能因此失去作用，故必须明确新的参数化和有效参数，不能称全部原参数作用不变。
4. **完整欧氏Conv10/BN10/Leaky或入球前BN作为更后续独立变量。** 这会改变表示与梯度，不和余弦头/恢复dropout打包。TAN已经恢复50部件的全局召回，尚无证据要求立即扩大结构矩阵。
5. **确认可复现性。** 当前成果需要匹配重复及多seed/独立验证协议才能形成可靠的方法结论；已训练trainval的模型不能把原val直接视作未见验证集。历史比较保留既定口径。

以上除第1项外均为建议，没有自动启动后继实验。
