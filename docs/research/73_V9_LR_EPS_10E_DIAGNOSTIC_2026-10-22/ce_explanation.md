# 分类正确、CE目标与有界logits的区别

这是对本次讨论中“80%目标”和“单位球限制”的澄清，不是本次代理实验的新增配置。十轮训练仍保留原分类头与标签平滑。

## 当前源码事实

V9使用`inter_hierarchy_MN40/models/pointmlp.py`的原生c=1模型，分类头为`MobiusLayer(256,40,manifold2)`，其40维输出直接交给`inter_hierarchy_MN40/hier_proxy_scratch_v9/base_protocol.py`中的log_softmax CE。中间没有额外logmap或输出温度/scale。Möbius运算将输出保留在单位Poincare球内；这里作为分数使用的是球的坐标，不是双曲距离。

标签平滑系数为0.2，实际目标为正确类0.8，其余每类0.2/39。这是每个训练样本的目标概率分布，不是目标准确率80%，也不是预测正确必须超过80%。准确率只判断最高分对应的类别是否正确；正确类概率只要比每个错误类高就能选对，没有固定的最小概率差。

## 上界如何得到

记40维logits为z，约束为||z||₂≤1。令a=z_y、b为39个错误类分数的均值，由Jensen不等式，错误类指数和至少是39exp(b)。另一方面，a²+39b²≤1，所以a−b≤sqrt(40/39)。因此

`p_y ≤ 1 / [1 + 39 exp(-sqrt(40/39))] = 0.06593834685`。

闭球中取a=sqrt(39/40)、其余各取−1/sqrt(40×39)达到这个界。严格开球只有上确界；实际共享分类器和数值投影未必能达到这个值。它是架构允许的普适上界，不是实测概率。

例如正确类分数1、其他39类全0时，正确类已明确最高，但softmax概率约为6.516%。每个样本都这样选对时，准确率仍可为100%。

目标分布0.8对0.2/39要求每个正确/错误分数差为ln(156)≈5.049856；球坐标的幅度预算无法同时提供这些差。这不是球内方向或双曲距离的表达能力上界。保持分数排序而统一放大logits就能增加softmax置信度，无需改变分类结果。

## 能推出什么

当前输出幅度与平滑概率目标不匹配：训练仍有约束内的最优解，CE仍能推动类别排序改善，但不能拟合它的目标概率分布。这不等于分类失效，也不意味着真实正确率只能6.59%。这里的“置信度”特指模型softmax输出，未证明其概率已校准。

代码事实只支持“沿用了0.2标签平滑，同时采用有界坐标作为logits”。没有找到作者解释这种组合意图的材料，不把它描述为刻意使用不可达目标迫使模型确信。普通无平滑CE的单点概率1也通常只在无限分数差的极限达到，但其无界logits可任意接近；本例是被固定幅度限制在约6.59%，问题更具体。

目标不可达本身不能证明whole类内方向必然坍缩、径向梯度持续强或主干一直强烈压缩；仍需结合真实梯度、分类头Jacobian和控制实验。本次十轮只检验代理LR/eps，不能同时据此验证分类头修改。

标签平滑可以作为训练超参数调整；比较分类优劣仍使用相同数据和评估协议下的OA/AA。不同训练平滑系数下的smoothed训练CE不能直接当作同定义指标；若比较CE/校准，应使用统一评估定义。
