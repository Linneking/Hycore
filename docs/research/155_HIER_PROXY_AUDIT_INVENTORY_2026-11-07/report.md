# 代理训练审查盘点：以原始HIER为参照

日期：2026-11-07。用途：为后续可重复使用的审查协议整理历史依据。本轮只盘点既有报告、统计表和实现，不新增服务器回放、训练或代理诊断；下文不是已经定稿的合格阈值。

## 1. 先区分我们想回答的四个问题

1. **有没有训练到：** 样本项、代理内部项是否提供梯度，优化器是否产生实际移动；哪些代理长期缺少哪种信号。
2. **有没有实现目标：** 实际选择出的祖先是否满足HIER的相对距离约束；是否另外表现出祖先深度次序。
3. **代理集合如何组织：** 使用是否集中，方向是否冗余，深浅与角色、类别广度如何关联。
4. **组织是否有意义：** 关系是否稳定，是否关联独立形态信号，以及对主任务有何作用。

这四层不能互相替代。收到梯度不等于形成层次，径向分层不等于形态结构，分类改善也不单独证明代理机制有效。

用户提出的校准原则是：如果把某个预期现象作为HIER组件的评价依据，应先确认原始HIER参考模型是否确实表现出这一现象。必须另作区分：**一个指标已在HIER上算过**，不等于**HIER验证了它应当单调提高或达到某个阈值**。

## 3. 审查机制清单

### 3.1 输入、权重和几何算子身份

**做过：** 核对checkpoint/缓存SHA、对象ID与标签、曲率与维度、BN/增强/推理batch、代理参数到底是切空间还是球坐标；用保存参数经原映射重建代理；官方FP32距离与独立稳定距离交叉复核；抽样重新前向与可信缓存比对，前后检查参数和BN未变。

**用途：** 排除“审查算错了空间或输入”的假象。例如原HIER缓存已经是球坐标，不能再次expmap；原HIER的PA分类代理也不是待查的512个HIER层次代理。

**原HIER对照：** 45/46已完成三份best与12缓存身份核验；真实图像anchors也核对通过。85/96另曾因前向上下文不匹配而拒绝读出，恢复原条件后才使用结果。属于所有后续项目的前置条件，不是训练效果分数。

### 3.2 代理深度、cap状态及时间变化

**做过：** whole/part/代理的深度分位数、直方图与ECDF；raw切空间模长、forward后深度、数值球投影分开；逐代理内外移动、首次越界、返回、持续越界时长，以及相对初始化的净位移；best/末轮/早期快照对照。

**已有发现：** 88的同LR、仅eps不同十轮配对中，e10越cap为500/512与0/512；大eps组曾越界的70个代理均曾返回。96发现初始化高斯范数有差异，并非所有代理都严格等深4.14。

**原HIER对照：** 三组whole均在4.6薄壳；CUB/Cars/SOP代理raw越cap分别9/1/497。因此“全部回cap内”“代理必须有宽深度分布”不是原HIER共同成功条件。原HIER现有best几何不足以恢复完整早期越界时间线。

### 3.3 采样图是否提供了可训练关系

**做过：** sample和proxy分别统计互惠邻居、合格anchor、i/j/k触达、跨类j比例、负候选、重复ID、self-k、A=B碰撞及每批draw数量；改变K进行冻结筛查；核查双卡gather、loss平均和代理同步。

**已有发现：** 合格anchor比例、被某个角色触达、被选成祖先是三个指标。V6后期proxy合格率很高，仍出现代理样本检索集中；V5少量self-k贡献了较多损失。

**原HIER对照：** 46保留官方self-k与碰撞规则进行回放；我们后续排除self-k属于实现规则差异，应明示。原版global180与本项目CB64/CB32不同，不能按批数或裸计数设统一门槛。

### 3.4 代理究竟有没有被用到

**做过：** 两个损失分项分别记录pair/triple祖先次数；进一步分全部硬选择、非碰撞选择、非碰撞且正hinge选择；代理内部项另记i/j/k输入角色；统计不同代理数、频率、熵有效数量、休眠/再激活和逐ID生命周期。

**已有发现：** V7消除了数值饱和但仍有sample-inactive群；V8全512个样本祖先都有效用过，但频率有效数仍低于512。96主体活跃291仅是样本S/C/T并集；合并同表内部祖先读出后是425，外段163中有76个被内部项选中。这仍只是有限冻结窗口的祖先选择，不是梯度覆盖。

**原HIER对照：** 46的源式真实图像无更新窗口中，三集sample pair/triple有效祖先均512；proxy pair约495–510、proxy triple均512。这是目前最直接的激活参照之一，但需同时固定窗口、采样机会和有效定义。

### 3.5 收到什么梯度，优化器又实际做了什么

**做过：** sample/proxy分项参数梯度及combined；full straight-through与固定祖先直接项对照；切空间梯度径向/角向分解；whole局部偏导与共享主干梯度区分；同状态固定噪声探针；真实AdamW更新、历史m/v、weight decay与cap Jacobian分析；固定m/v只换eps的反事实和实际一步重构。

**已有发现：** 未被hard选中仍可能有ST软反向信号；作为内部i/j/k也能有梯度。88首步原始梯度完全相同，更新范数却从1.79944变为0.446155，说明eps影响实际位移，不能表述为直接把原始梯度压没。代理内缩也不能单独证明目标学到了层次。

**原HIER对照：** 46前2batch的两分项full-ST梯度超过1e−8的代理均512；SOP虽497个raw越cap，径向占比约1e−6量级，角向信号仍存在。该阈值是当次检测口径，不是跨精度/维度的普适“训练充分”标准。原Cars保存的m/v及eps已核查，但缺当时当前g，不能伪造同期真实一步对照。

### 3.6 相对距离目标兑现了多少，径向祖先次序又如何

**做过：** 三个hinge各自和联合满足率、违反量、非碰撞分母、正hinge困难子集；在同一个ijk上计算h(pair)−h(triple)、祖先与各端点深度差；另报祖先选中端点自身的比例、排除端点后的次序及容差敏感性。

**已有发现：** HIER优化的是相对双曲距离差，不直接约束原点深度次序。85两套A1末轮sample三项严格次序超过92%，proxy内部仅约5–7%；固定4.6 whole壳加内层代理已自动保证一部分端点次序。因此“样本祖先浅”不能单独证明内部层次形成。

**原HIER对照：** 45中CUB/Cars样本pair有弱较深趋势，SOP约98.6%非碰撞pair−triple差在±1e−4内。46两角色集合高度重叠。未找到与85完全同条件、同容差的原HIER内部三项严格次序验收结果；不预设必须普遍成树。

### 3.7 不同祖先角色如何共享代理

**做过：** 同类ij的pair(S)、异类ij的pair(C)、triple(T)分组；每组不同代理等权的深度/最近类角度箱形图，以及按次数/选择概率加权的分布；角色交集、独占组合、同关系深度差；sample与内部项单独列账。

**已有发现：** 96的S25⊆C142⊆T291，深浅两段并非互斥pair/triple层。同关系非碰撞pair通常比triple深，仍可与角色池高度共享同时成立。

96为该权重确定的分段谷值约3.678，只描述这份分布，不适合固定为跨模型的内外层阈值。两段/多峰属于观察结果，而不是必须拟合出的结构。

**原HIER对照：** 45/46已有sample及内部pair/triple分析，支持角色共享，而不支持固定两群。96的S/C细分、深度双峰分段和所有概率加权口径，尚未在原三份HIER上完整统一复算。

### 3.8 反向近邻、样本覆盖与热点

**做过：** 每个代理从全样本池查top4/top16，统计不同对象覆盖、最大曝光、最热若干对象槽位份额、重复四元组、类别纯度；全代理与不同使用子集分别统计；另看whole→最近代理占用。96加入保持四邻居标签组成的随机重选对照。

**已有发现：** V7仅把whole等深，NN4覆盖由27变221；代理未变，说明原始检索有显著径向偏置。96样本活跃291个代理的top4只给1164槽，覆盖668个对象；最大曝光14，高于类组成匹配随机对照p95=4。

**原HIER对照：** 原CUB/Cars/SOP的严格距离NN4覆盖1646/1664/432；SOP明显有热点。不能设“原HIER无热点”的共同标准。固定壳下，方向排序与理想双曲距离排序等价，不是两项独立证据。

**必须保留的区别：** 代理→样本top4是展示/检索；样本三元组→祖先是训练方向。前者覆盖最多512×4=2048个对象，不能以覆盖全部训练池为目标；它也不是该代理的真实训练后代集合。

当前96报告开头有“几乎没有热点、符合原始HIER”的概括，但同文随机对照实际发现了热点，原HIER的SOP也明显集中。本次不覆盖用户原稿；盘点采用原始统计和对照，保留“相较旧设置部分冻结热点减轻”，不采用“没有热点”的判断。

### 3.9 方向、类别亲和与深度广度

**做过：** 类内/类间角分布、逐类统计、类中心热图、代表类对、方向锥与最近类角；代理两两余弦、公共方向长度R、PCA能量与有效秩；代理到类别方向的亲和、top32类别熵、深度与类别广度关联；原半径随机方向、整体旋转、去公共方向、仅统一whole深度等冻结控制。

72还将样本统一在c0.1深度4.6，逐对计算理想测地中点，对三点计算绝对minimax中心。Cars同类pair参考中心中位3.81540，V9末期4.59781，说明窄方向群体留给几何中心的径向余量很小。这是几何条件诊断：理想连续中心不是HIER相对hinge的目标，也不是有限512候选代理应到达的真值。

**已有发现：** V7有部分未用群方向冗余，whole类别方向却已分开。85总体角度会掩盖flower_pot–plant的局部纠缠；B05-A1深度与类别广度相关很弱。96同一对ij分别比较最佳内外候选，并只换深度或方向，发现外层方向较偏、偏深也加大评分劣势。

**原HIER对照：** CUB/Cars代理公共方向很小，SOP明显集中；三组均未进入最近细类90%方向锥。Cars类内中位约42.503°，V9末期约1.993°，但任务/数据/维度不同，40°或进入类锥都不能作为统一目标。随机方向常有更高覆盖，也不说明随机代理训练更好。

### 3.10 跨增强、噪声和训练时序是否稳定

**做过：** 同噪声复现、仅换Gumbel噪声的祖先一致率、跨增强NN4 Jaccard、跨轮祖先/邻居/最近类别保留；沿同代理ID追踪初始位置、方向净转动、早期机会与最终使用；BN模式和批次重组敏感性。

**已有发现：** “程序可复现”“换噪声身份一致”“跨增强一致”“长期绑定某类”是不同问题。96初始化深度与前5轮sample-pair使用相关−0.697，初始最近类角度相关−0.130；这是关联，不是初始深度的独立因果证明。

**原HIER对照：** 45同增强视图的NN4平均Jaccard也低，CUB/Cars约0.07–0.13，SOP约0.22–0.23。原三份best没有足够真实训练时序来校准长期绑定、早期捕获或再激活标准。

### 3.11 代理关系是否有形态意义，以及主任务是否获益

**做过：** 固定规则选代理，展示同代理top4点云；独立FPS64 Chamfer与嵌入距离的类内Spearman、扣随机近邻重叠、全池形态富集；原尺度与中心/单位RMS控制；匹配无HIER基线、best与固定末轮分开；固定模型的按类配对bootstrap。

**已有发现：** 40/53呈局部改善、轮次与指标依赖，未证明一致形态优势。53固定e300全池形态富集有正差，但best对比及其他指标未形成一致收益。96展示卡、标签纯度和径向次序同样不足以证明真实形态层次。分类成绩与代理几何也非单调关系。

**原HIER对照：** 有图像近邻、标签纯度与检索表现参照，但未建立与本项目3D Chamfer等价的独立形态真值及树级结构验证。不能要求图像HIER直接通过点云专用指标；应分别校准通用代理机制与下游形态证据。

### 3.12 PartHier特有的扩展检查

**做过：** 同对象p200/p400/p600/whole逐级深度链；A/B候选来自何种尺度、当前batch还是保存队列；候选曝光率、深度百分位、来源供给与真实/期望选择；Lord和HIER三项分别及联合满足；同对象part–whole角度、候选等深反事实和局部梯度。

**已有发现：** 94中p600与whole接近，四级链不稳定；A/B都偏好p200，未形成“大part专任pair、小part专任triple”。候选供给与径向评分共同影响选择。

**原HIER对照：** 原始HIER的随机可学习代理没有part尺度/队列/显式Lchain，不把这些作为通用代理协议条件。94的“原版”对照是原生HyCoRe，不是CUB/Cars/SOP的原始HIER。

| 低热点、高覆盖就是训练好 | SOP NN4仅覆盖432；随机方向可显著扩大覆盖；去均值扩大覆盖却降低部分纯度 | 是组织特征，不是单调质量分数 |
| 稳定代理应始终检索同几张图 | 原HIER跨增强NN4 Jaccard也较低 | 需相对噪声/增强基线解释，不预设高一致率 |
| 浅代理必然关联更多类、全局构成树 | 当前原HIER资料未给出统一验收 | 保留为待验证假说 |
| 有标签纯度或分类增益就证明形态层次 | 标签进入监督；现有审查没有独立层级真值 | 需另行验证，不能替代形态证据 |

## 5. 后续固定协议最需要统一的词与分母

- **合格anchor：** 关系挖掘资格。与任何i/j/k触达、祖先选择均分开。
- **祖先选择：** 必须注明sample或proxy，pair或triple，全部/非碰撞/正hinge，窗口及次数。正hinge是该关系仍有违反，不表示“更好”，也不是充分优化证明。
- **梯度激活：** 同一次选择下，分项full-ST原参数梯度的数值响应。必须注明坐标域、阈值、权重、精度及梯度聚合方式；与选中次数分开。
- **实际更新：** 优化器后的参数位移，另报映射后深度/方向变化。历史动量、坐标缩放和WD都可能使它不同于当前负梯度。
- **活跃并集：** 同时给sample、proxy和合并结果；内部输入端点、候选ST路径和祖先角色各列，不以单一祖先并集代表所有训练参与。
- **原始记录/条件回放/确定性读出：** 真实训练日志、best上的无更新源式回放、argmin几何读出三者分别标识。换seed的有限窗口不能称为真实训练历史。
- **覆盖：** 说明是样本采样覆盖、sample→祖先使用、whole→最近代理占用，还是proxy→whole反向top4覆盖。它们的方向和分母不同。
- **径向层次：** 在同一个关系内逐项检查，不用两个独立边际中位数相减；同时报告原距离hinge与附加径向次序，保留碰撞与端点自选分母。
- **HIER视图：** 固定壳方法用训练中实际4.6视图选择代理；原生whole另存，不把构造壳的性质冒充主表示学习成果。
- **统计重复：** 不把百万三元组、1000批冻结抽样或类bootstrap当作多seed完整训练重复。

## 7. 从盘点到固定协议仍缺什么

1. 把原HIER与我们的方法放进同一输出定义：尤其激活四种口径、S/C/T细分、内部关系、full-ST梯度、抽样机会和窗口长度。历史40批argmin与46自然一轮随机回放不能直接混比。
2. 对“径向祖先次序”“深度—类别广度”“初始化机会差异”等预期，补原HIER同口径证据后再决定是否保留为质量判断。目前没有共同数值阈值。
3. 原HIER参考应覆盖CUB/Cars/SOP三种已见状态，不把Cars选作唯一理想模板，也不把best条件回放称为完整原训练轨迹。
4. 分开最低训练机制检查、结构描述、异常原因诊断和独立形态效果。最终协议不宜把所有项目加权成一个“代理训练分数”。

原HIER交接的`proxy_eval/README.md`另列purity@4/@16、相邻代理top16重叠、全局代理对Jaccard、nearest-proxy占用熵/有效数量/零占用、GT分配AMI等入口。当前45/46没有逐项公开全部数值；本盘点只承认有定义/实现，不将它们记为“原HIER已经优于随机的项目”。

原HIER的真实图像无更新回放保留源式增强与BN规则，HIER读出使用CPU FP32；原训练在AMP上下文且历史RNG不完整，检查点还缺PA类别代理参数。其价值在于best条件下的角色与梯度机制参照，不能冒称原历史逐步重放、严格续训或更新后的任务收益。详见[原HIER恢复条件](../diagnostics/hier_original_resume_requirements_v1.md)。

本轮到此完成历史盘点；没有把新训练、服务器诊断或统一协议实现记作已执行。
