# H 与原 DGCNN 的逐类 IoU：以超越基线为目标

2026-11-01，只读服务器保存结果，未重新推理或训练。

## 比较口径

沿用历史统一口径，取各组最佳 Test Instance mIoU 检查点：DGCNN e186、H0 e173、H e197；Class与16类IoU均来自该检查点，不把不同轮次的各类最优值拼接。测试对象均2874个。这里的Class不是独立按Class选出的历史最高值。普通DGCNN与双曲组还存在尾部结构、优化器等差异，且H有硬件迁移，下面是诊断性差距分解，不构成单因素因果结论。

| 模型 | Instance mIoU % | 同轮Class mIoU % |
|---|---:|---:|
| 原DGCNN | 85.383 | 81.777 |
| H0 | 84.521 | 76.093 |
| H | 84.618 | 74.821 |

H的任务目标是追上并超过DGCNN。H0用于帮助定位正则的额外影响，不作为最终性能目标。

Class差值按各类差值除以16后相加。H相对DGCNN共落后6.956pp，其中rocket、bag、motorbike合计贡献−6.614pp，约占净差距95.1%。这三类只有77/2874≈2.68%的测试对象，但在Class平均中占3/16=18.75%，因而Instance差距小、Class差距大。

当前表中H只有5类比DGCNN低；其余11类数值相近或更高。不是整体所有类别都退化。cap测试仅11个对象，H还更高，也不能用“少数测试类必然失败”一概解释现象。

最终共同e200亦有差距：DGCNN Class82.187%、H74.724%，差7.462pp；不是只有best选轮不同才出现落后。

## 直接改变研究优先级

1. 首要对象：rocket、bag、motorbike；其次skateboard、earphone。重点是各自物类内部的部件识别，而不是仅比较物类预测——物类one-hot本来已输入。
2. bag在H0已只有45.571%，远低于DGCNN80.110%；rocket/motorbike在H0也落后。说明共同差距在不开R时就存在，不能只通过关闭/改正则解释。
3. rocket/motorbike从H0到H又下降，因此这两类既有“共同路径/训练配方差距”，又有“开启R后的进一步变化”。后者需要相同硬件、初值及协议确认。
4. 首先核对DGCNN、H0、H在三类上的部件recall、混淆和逐对象预测直方图，区分完全不预测某部件与边界不准，再据此决定读出或监督方案。不能只因测试样本少就立即更换batch或加权。
5. 若仅将H的这三类提升至DGCNN对应水平、其余类别不变，Class约81.435%，仍略低于DGCNN81.777%；这只是差距算术，不是性能预测，第二梯队也需要关注。
