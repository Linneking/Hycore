# H 的Class mIoU改进与原因定位计划

2026-11-02。用户要求根据已有检查制定下一步调整、提高表现并查明类别mIoU下降原因。本文件是待审阅计划；本轮没有启动新的诊断或完整训练。它把129的候选计划按130–132实际结果收敛为一个因果补充诊断及两个完整训练候选。

## 目标和当前可以成立的判断

历史best-Instance检查点同轮Class：DGCNN81.777%、H0 76.093%、H复跑74.754%；对应Instance85.383%、84.521%、84.623%。H复跑比DGCNN低7.023pp，H0已低5.684pp，所以正则不能解释全部差距。H0与H复跑差1.339pp只是成绩差，仍需匹配协议确认正则的因果增量。

固定e200的Class目标是DGCNN82.187%；H0为76.036%，H复跑74.750%。不同选轮口径不交叉比较。首要目标是超过DGCNN，不以超过H0作为成功终点。

现有证据：

|假设/现象|已有结果|对计划的约束|
|难类整体部件漏检|130确认H/H0多个部件在训练对象及测试对象的eval结果中召回为0|先恢复部件识别；边界优化后置|
|少数物类导致Class差距集中|旧H的差距分解中，bag/rocket/motorbike仅占2.68%测试对象，却占3/16类别，贡献约95.1%的净Class差距|保留全16类结果，重点关注三类及skateboard/earphone|
|BN统计单独导致漏检|131的三批BN切换未恢复零召回|不优先增加BN变体；该结论限所查批次|
|所有信息/梯度已消失|U和第一M之后仍能用线性探针识别多部件，CE能传至U|重点查读出优化；不能把问题一概解释为断梯度|
|监督尺度影响学习|132同特征、同原M起点，尺度5使rocket42召回从尺度1的.12%提高至20.81%|尺度5有局部因果支持，值得完整训练|
|初始化错误/必然径向死局|原M+普通CE也恢复bag至60.31%；尚未对随机初始化做对照|保持原初始化，不据此判定初始化错误|
|正则长期有害|H/H0有成绩差，但单步反事实的作用正负混合|保留完整R开/关，不能只凭一次梯度判断|

需要补清的混杂：131/132使用七类、每类相同数量的物体，较原自然训练大幅提高了小类比例；同时冻结前序特征并增加头部更新。132中B对A的尺度效应有效，但起点到A的bag恢复不能单独归于“原头只需多训”或“小类曝光”。

原DGCNN与H面对相同的数据不均衡，cap/mug又是少样本成功对照。因此真正要查的是**当前读出/优化与不均衡的相互作用**，不能把“数据少”当成足够原因。物类对象少与同物体内部件点数少也要分别检验。

## 一、补一个固定特征因果诊断

目的：把类别出现频率和尺度效应拆开，不把132的增强小类比例直接带入生产。模型固定H复跑e182，原始μ128、原最后M和完整RSGD状态；只更新最后M，保持原LR、4000更新和8192点/步。四格共用相同16类特征池和拟合/检查划分。

|拟合时物类出现概率|CE(z)|CE(5z)/5|
|---|---|---|
|训练集原始类别频率|N1|N5|
|16类等概率|U1|U5|

固定池：每类12个trainval物体，8拟合/4检查；七个已有类沿用132物体，其他九类按seed4780追加。类别不足或重复身份必须显式核查，不让同一身份跨拟合/检查。编码器曾见过trainval，此划分仅隔离读出拟合，不作为未见对象泛化证据。

按训练集完整类别计数构造自然先验p(c)=n_c/14007，均匀先验p(c)=1/16。两种先验均采用同一抽样算法：每步有放回抽32个物体位置，类内在固定拟合物体中均匀抽取，每个位置随机抽256个缓存点；维持物体内部原部件频率，不做部件均衡。同先验的两个尺度共享完全相同批次；跨先验使用配对随机流。所有μ先按完整2048点编码，再取缓存点，不能用256点重新编码改变邻域。

缓存池对每类的形状覆盖相同，所谓“自然”只复现类别先验，并非完整训练集重放；这一限制写入结果。该诊断没有BN更新、没有改变正则负例，因此只定位类别出现概率对最后读出的影响，不等于验证完整网络类别均衡batch。

判读预先固定：

- N5优于N1：尺度效应在自然类别先验下仍成立，增强完整训练依据。
- U1优于N1：提高小类出现概率本身对恢复有贡献；仍需保留对正常类别的影响。
- 主要只有U5有效：尺度与类别出现概率存在交互，132收益不能直接外推到自然训练。
- 均衡后motorbike小部件仍零召回：进一步考虑物类内部部件权重或读出能力，不直接宣称backbone信息完全消失。
- 四格均不恢复：这只约束当前冻结表示、起点、LR和预算；不直接否定fresh完整训练，也不据此扩展大规模超参搜索。

## 二、首轮完整训练：两个新组

暂用描述性名称，不复用历史A–I实验编号。只新增下面两组；已有H0和H复跑作为尺度1参考格。

|尺度|R关闭|R开启|
|---|---|---|
|s=1|已有H0|已有完整5090 H复跑|
|s=5|新S5-R0|新S5-R|

```text
共享前端：原DGCNN局部/全局/类别融合 → Conv8 + BN8 + Leaky
         → Conv9(256→256,bias=False) + BN9 + Leaky → U256

主支：U256 → EXP → M(256→128) → M(128→50) → z50
监督：CE(5·z50, y) / 5

R支路：U256 → whole/特征近邻part分别mean → EXP → Rcontr、Rhier
S5-R0：L = Lsup
S5-R ：L = Lsup + .01 Rcontr + .01 Rhier
```

两组从同一fresh初始化训练完整网络，绝不从e182或132末头续训。H的dp1/dp2删除、Conv9块、两M、正则分叉、原初始化均沿用；不冻结前端或第一M。只修改监督尺度和显式R开关。

共同生产配置：

- ShapeNetPart原trainval14007/test2874与相同数据manifest，全部16类、50部件；原自然shuffle、batch32、drop_last、N2048/k40，原增强与点序。
- seed4780，fresh200轮、每轮437更新，合计87400更新；原RSGD LR .1→.001的200轮余弦、momentum.9、weight_decay1e−4，无总梯度裁剪。
- BN每batch一次编码更新；part大小200–600、gamma=1000/part_size、delta4、批内异类负例；独立数据/part/negative随机流。
- 固定s=5进入CE，不缩放几何球点或R输入；推理仍原50类argmax。CE标签平滑保持原H关闭。
- 记录raw CE(z)、CE(5z)、实际Lsup和两项加权R。除以5只去掉显式5倍梯度因子，仍会改变CE/R的相对强度，因此监控共享U/Conv9上的实际梯度和更新。
- 新版本入口明确支持s与R开关，保留旧v6/v7可复现。默认s=1时与旧路径数值回归；R关闭应无训练梯度且观测不能消耗全局训练RNG。
- 沿用用户“直接训练，不要短测”的生产偏好：本地/CPU合同及静态核对完成后直接正式200轮，在正式首轮做初始化、数据、BN计数、损失和保存检查。上述单独研究诊断不计为生产前GPU短测。

复用旧对照的前提是核对初始化hash、数据、首批输入、随机流、模型/损失等价和运行预算。若身份无法充分匹配，第三个完整训练名额优先补同入口s1/R0，避免把版本差异当尺度效果；身份已匹配时不为凑三组重复训练。

四个比较回答不同问题：S5-R0−H0为无R的尺度收益；S5-R−H复跑为完整H的尺度收益；S5-R−S5-R0为新监督下R增量；二者都需要分别对照原DGCNN。若S5-R0改善而S5-R更差，只能说当前R设置在新监督下未带来收益，不能宣称尺度改善证明了正则有效。

第一节诊断可先完成并纳入解释；它不是新的200轮任务。即使N5局部不恢复，fresh完整训练仍是不同可检验假设，但应降低预期并保持本轮两个组的边界，不自动加尺度或结构网格。

## 三、把原因检验嵌入正式训练

主目标：全16类Class mIoU。保持历史选模口径，统一报告best-Instance同轮Class、固定e200（优先判断）、末20轮均值/波动。使用test每轮曲线沿用当前ShapeNetPart开发协议，不切换到test-best-Class，不把末段多轮视为独立种子。

新增detach统计尽量复用已有评估输出；固定训练诊断面板只作解释，不参与参数更新、不更改BN、不消费训练随机流。

|记录|回答什么|
|16类IoU及各类对总Class差值的贡献ΔIoU/16|总分是否主要因困难三类恢复，或损害其他类|
|50部件recall、precision、IoU、真值存在但整部件漏检比例|是否真正学会部件，避免只靠过度预测提高recall|
|每类/部件实际出现的对象、点数、有效更新次数|稀少对象和稀少部件究竟缺多少监督机会|
|困难部件正确类与主要竞争部件的margin、输出权重行模长|哪一轮开始形成竞争，是否曾学会后丢失|
|固定自然批次的部件梯度贡献与真实更新；CE/R共享层梯度|信号是否被其他点抵消，尺度下R是否相对更强|
|cap/mug及其余正常类的代价|避免只优化选中的失败类别|

常规指标每轮复用，详细诊断重点e1/5/10/20/40/100/200及既有监控频率。遇到数值或保存错误及时处理；不依据test-Class波动自动早停/临时改配方。

## 四、按结果选择唯一后继调整

1. **尺度有效、R开启也更好**：保留尺度5，进入匹配重复确认，再考虑更细改进。
2. **尺度有效、R仍降低Class**：用已有R全关/全开作两角，仅新增contrast-only与hierarchy-only定位分项。margin可达率不作为R有效性门槛；先看分割收益。
3. **类别频率诊断有效，生产自然采样仍漏小类**：先做一条有匹配对照的类别均衡候选，保持更新总数一致。完整采样改变BN和负例分布，其效果属于训练协议改变，不能归于双曲目标本身；需明确与冻结诊断的差别。
4. **物类内稀少点部件仍漏检**：优先温和部件加权，保留原batch。仅用训练标签频率，原129候选`raw=min(5,sqrt(max(f_c)/f_ck))`，再除以该物类期望权重，使每类期望点权重为1。先与相同读出/R设置的无权重组比较，控制类别总权重；检查precision与正常类代价。不能同时加入类别重采样、部件加权与结构改动。
5. **采样/监督仍无法恢复，μ128探针却可恢复**：把最后M换成能输出实数分数的双曲MLR作为单独结构候选，保持U处分叉；该参数化与偏置变化应明确标注，不能称官方复现纠错。若U明显优于μ128且读出调整无效，再针对第一M或尾部非线性做专门对照。

这些是有条件的后继，不是一次全部启动的矩阵。当前不优先恢复I、乱调曲率、改变初始化或重新扫dp/M层数。

## 五、资源与结论边界

按最近H约5小时56分钟/200轮估算，两组约12 GPU小时；两张卡可并行约6小时，一张卡依次执行约12小时，真实耗时以后续启动状态为准。仅使用启动时完全空闲GPU，不指定当前卡号、不打断别人任务。若仅一张卡，优先S5-R0再S5-R以先检验共同主支问题。

一次seed4780的方向性收益不足以形成论文结论。候选明确后再固定独立验证协议，用DGCNN、选定R0/R组做匹配多seed确认。已在trainval训练过的检查点不能把其中val当独立验证；新验证协议必须重建对应基线，不混合历史分数。
