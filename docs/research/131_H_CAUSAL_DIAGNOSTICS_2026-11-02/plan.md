# H/H0 因果定位：第一、二步

用户于2026-11-02明确授权按上一轮计划开始实验审查。本阶段使用已有DGCNN、H0和H复跑检查点，不新增完整训练。

固定seed4780，从trainval中为bag/rocket/motorbike/skateboard/earphone/cap/mug各抽4物体，加4个其他类物体，组成32物体一批；共三批，第一2048点。类别比例人为增强，不能把诊断梯度贡献当作自然训练分布的贡献。物体索引和身份仅服务器保存。

1. 回看H0和H复跑的e0/1/5/10/20/30/40/50/100/150/200实际存档；缺失即记缺失，不用替代模型。记录固定训练对象的逐部件召回、预测点数、正确类概率和合法部件margin。稀疏存档只能限定变化区间。
2. DGCNN/H0/H最佳Instance检查点比较eval与仅BN使用当前批统计。所有dropout关闭；不修改BN参数/缓冲，逐模型校验前后state hash相同。
3. H/H0最佳检查点从detached U256开始重放EXP→M256128→M12850→CE。记录各部件在U/EXP/M128/Z的梯度及径向/切向分量、原始与有效M权重模长、原始参数上困难部件与其他点的贡献及夹角。困难部件损失保留整批B*N分母，不擅自再加权。

边界：本阶段无优化器更新、无正则反传、无更早backbone反传，不能声称已验证实际更新方向、长期正则因果、全部backbone梯度或特征可分性。读出探针及完整优化器的一步反事实更新根据本阶段结果选择。
