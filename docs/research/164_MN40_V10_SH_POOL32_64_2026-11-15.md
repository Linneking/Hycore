# ModelNet40 V10 单卡 Shuffle 搜索池对照

**当前执行版本是 TS39–TS41，采用 TS06 的全训练集和逐轮测试 OA 选模。** 下方保留已停止的 VS984 版本记录。[跳到当前方案](#ts06-口径重跑)

三组按同一自然 shuffle 取样。每次把连续两个 32 样本小批次用于一次主网更新。每次前向的 BN 统计及 HyCoRe 批内反序关系仍按各自的 32 样本计算。

| 组 | HIER 样本关系搜索 | 比较 |
| --- | --- | --- |
| B17-H0 | 关闭 HIER | 这套 2×32 更新协议的匹配基准 |
| B17-H32 | 两个 32 分开搜索，按抽取关系数量加权 | 对 H0 检验 32 池的 HIER 增益 |
| B17-H64 | 合并相邻两个 32 搜索，允许跨小批次关系 | 对 H32 检验扩大搜索池，对 H0 检验 64 池的 HIER 增益 |

- 共同主网沿用 B05 几何和损失。曲率 .1，切空间 cap 2.3，出口 GS，margin 500/N 与 2，RiemannianSGD 学习率 .1 到 .005，动量 .9，weight decay .0002，一次更新前裁剪总梯度到 1。保留全局与局部前向顺序、增强和裁剪视图。两条开启组沿用 TS35 的 Hshell A1、Ks20/Kp20、λ=.5、W0、512 代理、初始化系数 .9、壳深 4.6、每锚 T50。每个主网更新计算一次代理内部项，AdamW 学习率 .005 到 .0005、eps 1e−4、weight decay .01。使用独立采样、样本 Gumbel 和代理 Gumbel 随机流。
- 共同预算为单卡 300 轮，从头训练，训练 seed4780。复用 VS984，划分 seed22，训练 8,856 对象，验证 984 对象。每轮 276 个完整小批次、138 次更新，共 41,400 次更新。每轮按验证 OA 选模，同分取较早轮，报告对应 AA。官方测试集 2,468 对象在训练结束锁定权重后只评估一次。
- 两个开启组先取两批嵌入，再逐个重算小批次反传，释放中间激活。重算恢复 BN 缓冲区和随机状态，使同一个小批次只保留一次 BN 更新。所有组关闭 cuDNN benchmark 以保持重算一致。
- 8001 上用 GPU 0 和 GPU 2。每组先验收两次更新、共同输入指纹、实际采样池和 BN 更新计数。正式 H0 和 H64 先并行，H32 等其中一张卡完成并重新通过空闲检查后自动启动。

历史 TS06、TS35 使用全训练池、逐轮测试选 best，每 32 样本更新一次。这批以 B17-H0 为直接对照。历史 TS06 的 94.327% 保留为项目目标参照。
