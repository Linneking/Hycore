## 2. 固定的主模型候选

详见[审查报告中的两组流程图](audit_report.md#2-对照流程图模型主干与输出)。主候选一次列明，避免实现时临时换层：

| 阶段 | 模块与输出 | 变化 |
|---|---|---|
| 局部编码 | 原四层EdgeConv：64/64/128/256，拼接L为[B,N,512] | 保留原模块与连接；仅设备索引兼容修正 |
| 点级高维映射 | 原conv5：512→1024，输出[B,N,1024] | 保留 |
| 全局上下文 | 原max+avg→2048，原linear1→512、BN6、LeakyReLU(.2) | 完整保留，输出g[B,512] |
| 点级融合桥 | concat(L,广播g,物体类别one-hot16)为1040；无偏置Conv1d1040→512、BN、LeakyReLU(.2) | 新增分割接口，输出H[B,N,512]；不新增dropout/STN |
| 双曲映射 | 原PoincareBall(c=1).expmap0(H) | 对每点复用原运算 |
| 双曲嵌入 | 原MobiusLayer emb：512→256 | 完整保留_weight/_bias/transp0/初始化 |
| 部件读出 | 原MobiusLayer mlr：256→50 | 实现保留，输出数40→50 |
| CE | logits[B,N,50]、targets[B,N]展平，复用cal_loss | 物体监督改成逐点监督 |

类别one-hot是当前ShapeNetPart协议中已知的物体类别，仅作为模型输入和异类负样本筛选；正则part不用真实部件标签。论文未明确该分支，故列为分割工程选择。

该方案最大限度保留官方分类模型；它是有证据约束的原生适配，不宣称逐层等同论文未公开的分割实现。全模型参数量相对AnTao baseline不同，报告实际计数及来源。H0/HC同架构同初始化、参数量完全相等。

## 3. 从分类损失改造分割损失

复用官方 `hype_triplet_losses` 的dist/dist0和hinge核心，沿用其ball_dim参数并显式设为512；迁入版本新增显式负样本/有效掩码入口及几何对象设备处理。先以原flip/原方向设置证明数值与梯度一致，再在seg调用中设 `opposite_hier=True` 和合法负例。

1. 每个物体只运行一次编码器，取得双曲头之前H。
2. 从H特征空间采part：每物体一个随机中心；每批共享一个200–600的均匀整数N′；平方欧氏近邻，包含中心，并列按点索引稳定处理。规则沿用可用v1实现，明确这是论文未完全指定的重建约定。
3. whole对全部H平均，part对选中H平均；然后分别调用官方expmap0，得到512维球嵌入。保留选中特征值的梯度，离散索引不求导。
4. 负part从其他物体且不同物体类别中均匀选择。无合法负例的anchor跳过对比项，层次项仍计算；记录有效比例。单类别批次不能悄悄构造同类或自身负例。
5. 固定公式：

   `Rhier = mean(relu(dist0(whole) - dist0(part) + 1000/N′))`

   `Rcontr = mean_valid(relu(dist(whole,part) - dist(whole,negative_part) + 4))`

   `L = CE + .01*Rcontr + .01*Rhier`

6. H0与HC均构造相同模型；H0关闭两正则且不构造采样器。HC使用独立part/negative RNG，不改变数据打乱、增强或模型初始化随机流。对两组记录完整初始state hash和首批输入hash。

## 4. 训练协议：来源和主建议

以下是本次待审的具体主建议，必须保存解析后的配置。它区分用户已定、原生训练继承和分割适配，不把分类默认冒充论文分割配方。

| 项目 | 主建议 | 依据/与v1的区别 |
|---|---|---|
| seed | 4780 | 用户已定 |
| 数据/选模 | 现有trainval14007/test2874；逐轮test unmasked Instance mIoU取>=保存，并列后轮；固定200轮、无early-stop | 用户已定；原数据缓存不改 |
| 输入/batch/图邻域 | XYZ2048点、batch32/eval16、k40 | 沿用既定分割协议；须先通过新模型显存门槛 |
| 优化器 | 官方RSGD，momentum=.9，WD=1e-4 | 原生继承；H0/HC一致 |
| LR与调度 | 初始.01、200轮cosine至.0001 | 优先恢复官方分类入口默认LR及LR/100；v1为.1→.001，属于明确协议变化，不把差值归因于正则 |
| 梯度裁剪 | 总损失反传后clip_grad_norm_=1，记录裁剪前后范数 | 官方活动代码有此行为；v1未裁剪 |
| CE | 复用官方cal_loss，但显式smoothing=False | 保留现有分割普通CE及论文经典CE的工程解释；原分类实际默认True/eps=.2，故这是有意适配，不称原入口原样继承 |
| 双曲设置 | 官方c=1、原exp和完整MobiusLayer；不加温度、额外归一化/cap/hook | 源码优先；数值问题用验收揭示，不悄悄修配方 |
| part和系数 | N′200–600，1000/N′与4，两项均.01 | 用户已定margin及论文/既定分割设置 |
| 精度/运行 | FP32、单卡；workers8/cpu_threads4按环境能力 | 工程选择；新结构不直接沿用v1速度估计 |

本计划选择了native LR=.01及clip1，同时显式保留分割plain CE。若用户审阅后调整其中任一项，实施前更新整张配置表，H0/HC共同采用；不在两臂间混用，也不从test分数反推作者缺失设置。

数据仍来自已固定的公开normal-bearing版本去法线、XYZ归一化/first2048适配，并非原Stanford HDF5逐位复现；原raw成员规则含重复身份。复用缓存及SHA，保留该局限，不在本轮顺便改变成员/采样造成新变量。

## 5. 实施及验收顺序

### A. 固定来源并建立组件回归

新增 `source_manifest.json`、组件映射与兼容差异。测试比较的是原实现，不只测试新实现自己的公式：

- 相同输入和完整state下，原MobiusLayer与迁入版本输出、输入梯度、_weight/_bias梯度一致；不能只比较matvec函数。
- 原图特征、四层局部输出、conv5、全局池化、linear1/bn6保持原路径结果；eval模式测试前向，train模式单独检查BN更新。
- 使用相同球对象和负例，迁入关系核在原分类设置下复现原函数；再用简单解析样例核对相反方向、1000/N′及有效负例mask。
- CE平滑开/关均对原cal_loss回归，正式配置显式关闭；裁剪及RSGD首步与完整状态恢复另行核验。

### B. 逐点接口与论文语义验收

- 验证H[B,N,512]、mu[B,N,256]、logits[B,N,50]；相同逐点输入用flatten执行与共享头逐点执行相同。
- 验证whole/part来自H欧氏池化后exp，不能取post-emb mu；确认单次编码、每批每个BN仅更新一次。
- 选点置换同步作用于标签；feature part索引合法，选中特征保留梯度；正例同物体、负例异物体异类。
- H0/HC模型state和首批输入完全一致；正则RNG不影响CE数据流；H0不产生额外采样调用。
- 打印逐模块参数、_bias清单、H0/HC总量及普通有偏置Linear对照，验证推导144178头参数和新增融合参数。
- 共享融合层和至少一个原encoder参数都检查CE与正则各自梯度；原emb/mlr的_weight/_bias由CE获得有限梯度。不要误要求正则直接更新下游emb/mlr，论文正则位于它们之前。

### C. 完整尺寸短测后才进入正式训练

实现通过后才部署；先查空闲GPU，在新目录做batch32/N2048、2轮×2步的train-only/无test短测，采用正式200轮调度。H0/HC分别检查有限损失、非零必要梯度、显存、完整保存/恢复和实际更新计数，然后fresh初始化。

记录H模长、exp前后半径/投影比例、whole/part深度、设计间隔满足率、有效负例比例、各层梯度及裁剪触发比例。高投影率需要解释；全程NaN-free并不代表几何正则有效。如果完整尺寸OOM，不私自减batch/点数并冒称相同协议；保留失败证据，先给出调整方案。

本地改码测试→专用分支commit/push→服务器隔离部署fetch/pull --ff-only。新目录记录源码、配置、seed、GPU、环境、开始时间及fresh/无教师身份；不改已有结果。
