# 基于HyCoRe官方DGCNN的HyCoRe-seg v2复现计划

日期：2026-10-28，按用户三条批注修订。状态：**待审设计，未实现或启动v2训练。** 本版覆盖先前1040融合桥候选和默认替换flip的建议。旧v1、原分类路径和结果保持。

后续用户认可P0简单结构，并认可与DGCNN式全局特征拼接做消融的方向；本计划据此固定主结构与Pglobal候选。该认可不扩展为新训练启动授权。

## 1. 起点和最小结构改造

固定官方提交 `ef56a73020e309b1009c486fea1f601d3f7b3252`，从 `classification_ModelNet40/models/dgcnn_hmodel.py` 活动代码迁移。新代码放 `segmentation_ShapeNetPart/hycore_seg_v2/`；原绝对导入和硬编码cuda仅在隔离子包适配，保留来源清单与最小差异。

主候选P0：

```text
XYZ [B,N,3]
→ 原四层EdgeConv，64 / 64 / 128 / 256
→ 原内部拼接L [B,N,512]
→ 原conv5，T [B,N,1024]
→ 不执行分类末尾global max+avg，保留N
→ 原linear1改为1024→512，逐点共享、bias=False
→ 原BN6 / LeakyReLU(.2)
→ H [B,N,512]
→ 原expmap0 / 原emb512→256 / 原mlr256→50，逐点共享
→ logits [B,N,50]
```

Linear对最后特征轴映射；BN6处理[B,512,N]或[B*N,512]，不能把[B,N,512]直接当BN1d的通道布局。可用等价1×1卷积验证数值，但主实现固定逐点Linear，延续原模块类型。

主方案**不输入类别one-hot、不新增融合桥、不增加额外局部绕接**。原内部四层cat本来就在官方encoder中，保持其结构。类别元数据仍用于按类mIoU和flip配对类别统计，并非网络输入。不加载旧分类checkpoint；全部从seed4780初始化。

去掉显式global上下文、调整linear1入维及BN统计范围都是任务适配，需要用H0检验；不保证精度不变，也不能称为已恢复论文未公开逐层结构。

## 2. 正则与原码负例行为

保持单次编码H、特征空间part、逐物体欧氏平均后exp：

- 每个H_i为[N,512]。whole_i平均该物体N个点；part_i平均该物体I_i中的点。输出whole/part均为[B,512]，禁止跨batch物体平均。
- 每物体随机一个中心；每批共享均匀整数N′200–600；平方欧氏特征近邻、包含中心、稳定并列规则。这些采样细节是重建约定。
- 离散索引不求导；选中特征和负part特征保留梯度。
- 复用官方dist/dist0/hinge与mean，原ball_dim显式设512，使用opposite_hier=True，目标part比whole深。
- 层次margin1000/N′、对比margin4、两项系数各.01，按用户既定决定。

两篇论文负例都定义为异物体异类；官方源码默认flip没有类别判断。按用户最新要求，**P0原样保留negative=flip(part,batch_dim)**，不默默过滤、跳过或替换同类配对。新增日志记录same_class_pair_fraction与self_pair_fraction；batch32且drop_last时flip不会自配，但仍可能同类。

“batch含至少两类”只保证存在异类候选，不保证flip选中；shuffle也不是类别配对约束。原码兼容性与论文异类语义分开报告。严格异类筛选只列后续待审对照，不作为本版主配置。

正则模块只返回：

`Lreg = .01*Rcontr + .01*Rhier`

训练入口另算CE，再合并一次：

`Ltotal = LCE + Lreg`

共享backbone接收两条分支梯度，独立emb/mlr只接收CE。不得重复把CE加入正则模块，也不得detach共享H。H0与HC同模型同初始化；H0不调用part采样器，HC使用独立part RNG。

## 4. 参数预算

相对原40类分类模型：linear1从2048×512变为1024×512，减少524288；mlr40→50增加2570；合计**减少521718**。完整双曲头参数仍为144178。

H0/HC完全相同。比较论文总参数量时必须声明此原生适配与原DGCNN分割结构不同，不称论文“参数不变”已复现。实际模型构建后复核所有计数。

## 5. 验收顺序

1. 固定来源，核对原图特征/四层encoder/conv5、MobiusLayer输出、输入梯度及_weight/_bias梯度；兼容修正与数学变化分开。
2. 验证取消global池化后T[B,N,1024]和H[B,N,512]；原linear1新入维与逐点共享一致，BN轴正确且每批只更新一次。
3. 验证head直接处理B×N点、输出[B,N,50]，与展平后调用相同；不用分类输出reshape冒充逐点预测。
4. 验证逐物体平均、特征part索引与梯度、原flip配对精确一致。用标签[A,B,B,A]的合成例验证统计能识别同类配对，但正式主候选不修补它。
5. 验证分类损失核在原设置下回归，以及opposite_hier=True的径向方向、1000/N′、512维几何。
6. H0/HC模型完整初始state和首批输入hash相同；HC独立RNG不改变CE数据流。测试类别标签不作为网络输入。
7. 共享层分别读出CE和正则梯度；head只有CE直接梯度。记录H范数、投影比例、深度/间隔满足率、配对同类比例和裁剪触发。
8. 完整尺寸batch32/N2048的2轮×2步无test短测，正式200轮调度；有限模型/梯度/优化器、完整保存与恢复、显存和更新计数通过后fresh训练。失败保留证据，不悄悄减batch/点数改协议。

本地编辑测试→独立分支commit/push→服务器隔离fetch/pull --ff-only；新目录记录源码/config/seed/GPU/环境/开始时间/无教师与fresh身份。只用完全空闲GPU，不动旧结果。**本轮没有实施上述步骤或排队新训练。**

## 6. 实验顺序与可选消融

先验收并训练原生P0-H0（无正则），然后同结构P0-HC（两正则）。既有AnTao/v1只作外部与历史参照；不同架构和协议的差值不当作纯正则收益。

后续消融候选，不自动启动：

| 候选 | 相对P0的变化 | 解释边界 |
|---|---|---|
| Pglobal：全局特征拼接（用户认可方向） | concat(T1024,broadcast(max_N T)1024)=2048→512 | 比P0增加524288权重；其他结构/训练协议匹配，无one-hot |
| 原生欧氏头 | 同encoder与逐点投影，头换等宽有偏置Linear | 检验头部效应 |
| 严格异类负例 | 单独改变flip策略 | 检验源码行为与论文语义差异 |

不在主方案预加新结构或额外矩阵。修订前桥方案及相关参数计数留在Git历史，现行流程见[审查报告](audit_report.md)。

Pglobal的2048由逐点特征与全局max组成，区别于分类版max+avg；用原linear1(2048,512)的模块形式逐点调用，并保持BN轴正确。头部仍是exp→emb512→256→mlr256→50两层，不随该消融增层。原分割尾部1280→256→256→128→50仅供任务结构参考，不自动搬入本原生路线。额外低层多尺度绕接暂缓，不与Pglobal同时增加。
