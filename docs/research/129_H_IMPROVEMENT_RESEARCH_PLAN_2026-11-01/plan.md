# H 分割表现改进研究计划

日期：2026-11-01。状态：供用户审阅的研究方案，尚未实施新增诊断、代码或训练。已授权的 H 复跑继续按 [128记录](../128_H_RERUN_2026-11-01/execution.md) 独立运行，本计划不改变它。

## 1. 目标及现有证据

目标是超过原 DGCNN 的 Class mIoU，并报告 Instance 和全部16类的代价。历史口径为各组最佳 Test Instance 检查点及其同轮 Class：

| 模型 | Instance % | Class % | 检查点 |
|---|---:|---:|---|
| DGCNN | 85.383 | 81.777 | e186 |
| H0 | 84.521 | 76.093 | e173 |
| 旧 H | 84.618 | 74.821 | e197 |

固定e200时 DGCNN Class为82.187%，H为74.724%，H0为76.036%；不同口径不交叉比较。来源：[126逐类比较](../126_HYCORE_SEG_REASSESSMENT_2026-11-01/dgcnn_category_comparison.md)。

H落后DGCNN约6.956个百分点，其中rocket、bag、motorbike贡献约95.1%。这三类恢复到DGCNN水平、其余不变，Class约81.435%，仍略低于基线，因而skateboard、earphone和其余类别也要持续报告。

[127统计](../127_SHAPENETPART_DIFFICULT_CATEGORIES_2026-11-01/report.md)确认五个退化物类都是少样本类；cap/mug是重要成功对照。bag/rocket的H分数与“只预测最大部件”的理论值一致，但逐点预测尚未核验。H0也明显落后，不能把共同问题全部归因于正则。

工作假设分为：
1. 最后球坐标直接作为CE分数，限制训练的分类分数范围，可能使少数部件的学习更困难。
2. 物类内部小部件点数少，监督贡献不足；这与物类对象数少不同。
3. whole/part正则可能在某些类别上损害点级判别，须在同一读出下判断其增量。

以上均为待验证假设，不是已经证明的原因。H的R绕过M符合分割论文；不以I的BN诊断为前置，不把margin满足率设为有效性门槛。

## 2. 第一步：利用既有检查点定位失败

对象：DGCNN、H0、旧H的best与last；新H按训练完成后相同口径加入。相同对象和点序、eval模式、无参数更新。训练集也检查困难类别与cap/mug，判断训练阶段已漏部件还是主要在测试泛化时失败。

一次输出全部16类，重点列rocket、bag、motorbike，再列skateboard、earphone，并保留cap/mug对照：

| 统计 | 目的 |
|---|---|
| 50个部件的真值/预测点数、IoU、recall、precision | 确认哪些部件漏掉；预测数为0时precision标未定义而非伪造数值 |
| 逐对象的预测部件数、最大部件占比、真实存在却完全未预测的部件比例 | 区分整个物体恒预测主体和仅部分对象失败 |
| 物类内部混淆、预测到物类外部件的比例 | 确定主要竞争类别；原50类argmax为主结果 |
| 正确部件与主体部件的logit间隔、正确部件排名、正确类概率，按部件分组 | 查输出排序失败，而不只看总CE |
| 按部件点数占比分组的错误 | 查少数点部件是否系统性受损 |
| 必要时的空间边界/内部错误 | 部件均有预测而仍低IoU时，才进一步定位边界 |

合法部件mask只作为附加诊断；若以后改变训练/推理mask，需单列协议。边界邻域尺度需预先定义，不能用低recall直接推断边界问题。预测明细留服务器，研究记录只存汇总。

机制补充限于能回答任务问题的量：对固定训练诊断批次记录CE、加权Rcontr、加权Rhier在Conv9及共享前端的梯度范数和夹角，观察部件判别被加强还是削弱。诊断若改变批次类别组成须注明其为分层探针，不把它当正常训练分布；不更新参数或BN缓冲。几何贴边与径向梯度仅作辅助解释。

分支决策：
- H/H0训练集也漏同一部件：优先读出/点级监督候选。
- 只有H较明显：优先确认R的增量与分项影响。
- 训练好、测试差：泛化/形状覆盖优先级上升。
- bag/rocket恒预测假设被否定：按实际错误重新排序，不坚持预设诊断。

## 3. 首选改动：分类分数尺度，保留H的层次

公共路径只声明一次：

```text
原DGCNN局部/全局/类别融合 → Conv8+BN8+Leaky
→ Conv9(256→256,bias=False)+BN9+Leaky → U256
  ├─ 主支：EXP → M(256→128) → M(128→50) → z50
  └─ 正则：whole/特征近邻part分别mean(U) → EXP → Rcontr、Rhier
dp1、dp2删除；每batch一次whole编码。
```

候选只改变z50到监督损失的映射：

`Lsup(s) = CE(s·z50, y) / s`，固定首候选 `s=5`。

原因：目前最终M输出为球坐标，FP32 c=1时半径约不超过.996。50类下，该约束给出理论正确类概率上限约5.286%；这是理想约束界，并非每点实际概率。乘5后理论上限约75.745%。因此尺度能显著改变训练时softmax竞争，不需要同时改曲率、EXP或正则位置。推导及代码事实见[126](../126_HYCORE_SEG_REASSESSMENT_2026-11-01/report.md)及[本轮读出核查](readout_evidence.md)。

该上限不限制argmax准确率，官方分类也采用类似球坐标读出，因此不能据此认定它一定导致分割退化。s=5是预先声明的单一工程候选，不是文献最佳超参；不在测试集上搜索s。

除以s的理由：

```text
裸CE(s·z)       对z的梯度 = s·(softmax(s·z)−onehot)
候选CE(s·z)/s   对z的梯度 =    softmax(s·z)−onehot
原CE(z)        对z的梯度 =    softmax(z)−onehot
```

这样去除显式整体s倍放大；概率变化仍会改变各点梯度、共享层梯度及CE/R比例，不能声称已经完全匹配优化强度。它也不等同于乘一个CE权重。分别记录原始CE(z)、CE(sz)、实际Lsup和两项加权R，避免把不同标量的下降当作性能收益。

s只用于CE分数，不作用于球点的几何计算；只在推理时缩放旧输出不会改变argmax和mIoU。

## 4. 第一轮最小矩阵：新增两组

| 监督 | R关 | R开 |
|---|---|---|
| CE(z)，s=1 | 已有H0，先核验配对身份 | 当前H复跑 |
| CE(5z)/5 | 新候选S0 | 新候选SR，+.01Rcontr+.01Rhier |

S0/SR仅为方案别名，尚未分配正式实验编号或GPU。

共同固定：H结构、原初始化/seed4780、数据/点序/增强、shuffle/drop_last/batch32、N2048/k40、RSGD .1→.001/200轮余弦、momentum.9、WD1e−4、无梯度裁剪、BN一次更新、part/negative独立随机流及原监控。新候选必须使用同一新版本入口；不能改正在训练的冻结源。现有v6/v7分别锁定R全开/全关，未来需在版本化后继中显式支持此矩阵。

沿用用户“直接训练，不要短测”的安排，新训练方案不附带额外GPU短测；具体执行仍须用户审阅本计划后授权。

复用H0前核对源实现、初始化hash、数据manifest、首批输入/随机流、环境、训练预算和监控。若不能配对，明确剩余混杂，并将补一条H0列为所需控制；不把F0和H0算作两个独立seed。

四个问题分别由以下比较回答：
- S0−H0：新监督是否改善无R模型。
- SR−新H：新监督是否改善完整H。
- SR−S0：新监督下，R是否有增益。
- (SR−S0)−(新H−H0)：R增量是否随监督变化；单seed只作描述，不作显著性证明。

当前H与旧H同seed复跑主要用于核对重复性及硬件历程影响，不构成第二个随机种子。如果新H与旧H差别很大，应先核对运行身份再解释候选收益。

## 5. 第二轮按证据选择一个方向

### 5.1 少数点部件仍系统性消失：物类内部温和部件加权

保持上一轮确定的读出和H层次，在每个物类内部按训练集部件点频率计算权重。一个可审阅的固定候选：

```text
f[c,k] = 训练物类c中部件k占点数的比例
raw[c,k] = min(5, sqrt(max_j f[c,j] / max(f[c,k], 1e−6)))
w[c,k] = raw[c,k] / sum_j f[c,j]·raw[c,j]
Lsup = mean_points(w[c,y]·CE(s·z,y)/s)
```

频率仅由训练集得到，所有物类使用同一规则，不针对测试低分类专门加权。每物类的期望点权重归一为1，减少无意间同时加大少样本物类总权重的混杂；实际损失与梯度仍会变化。截顶与平方根避免极少数点获得过大权重，数值是候选设置而非最优结论。

此时做与选定读出相同的R开/关配对。类别均衡batch放在更后：它改变物体出现频率，也改变BN与批内负例分布，却不直接解决单个bag内6.7%/93.3%的部件比例。相关ShapeNetPart研究的收益与代价见[127文献](../127_SHAPENETPART_DIFFICULT_CATEGORIES_2026-11-01/literature.md)。

### 5.2 固定读出后R仍损害困难类：拆两项正则

复用同读出的全关、全开，只新增contrast-only与hierarchy-only，系数保留各自.01。用这四格定位两项单独作用及交互；不同时改margin、part采样或BN。

判据是Class/逐部件识别，而不是必须满足全部层次hinge。若某项只改善几何而持续损害分割，不为提高满足率继续放大它。

### 5.3 尺度改动不足且证据指向判别器：真正双曲实数读出

后备结构：

```text
U256 → EXP → M(256→128) → μ128 → 双曲MLR → 实数分数50 → CE
```

正则继续在U处分叉，仅替换最后的M(128→50)。双曲MLR使用类别超平面得到实数分数，不要求50维分类分数仍为球坐标；原型距离读出也是可选路线，但本阶段只选一种。此改动改变参数化、偏置和判别能力，需记录参数量，不称为只调尺度或官方HyCoRe-seg代码修正。公开双曲分割参考见[读出证据](readout_evidence.md)。

## 6. 评价与停止扩展条件

第一轮保持历史训练数据和选模口径作工程比较：报告best-Instance同轮Class、固定e200、末20轮Class/Instance均值与波动、全部16类和困难部件recall/漏检。末段多轮来自同一次训练，不能当独立重复。重点看Class，但不改用test-best-Class来制造表面收益。

- 尺度只让loss变小、Class和部件识别无改善：不继续盲扫尺度网格。
- recall上升而precision崩塌、其他类别明显下降：不能只靠困难三类判定成功，需看整体Class/Instance和误分。
- 读出或加权有效但R开不胜R关：可以认定监督/读出改进，尚不能宣称双曲正则有贡献。
- 新H不能重复旧H行为：先检查身份和运行历程，旧H只作历史参考。
- 没有稳定方向前不继续添加I变体、dp/M层数、曲率、采样器等同时变化。

候选形成后再做独立确认：预先固定真正未参与训练的验证集，以validation Class选模；DGCNN、胜出R关/开组用同一协议和至少3个匹配seed重跑，官方test只作最终评估。已经在trainval训练过的模型不能把其中val子集当独立验证。当前测试集已被多轮研究观察，须如实描述开发偏差；验证协议的成绩不能直接替代历史trainval结果。已有重复ID问题应在这一阶段一起明确处理，并重建对应基线，不把协议修正收益算成方法收益。
