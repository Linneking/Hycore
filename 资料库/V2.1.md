# 双层双曲层级框架 v2.1：完整方法说明

## ——面向三维点云分类与分割任务的 Inter-Sample Hierarchy 显式建模

---

## 一、框架总览

### 1.1 核心主张

现有双曲点云工作（HyCoRe、DMR、HIPO 等）仅在单个样本内部建模 part-whole 层级关系（intra-sample hierarchy）。不同样本之间——尤其是同类样本的实例之间——在双曲空间里的层级结构从未被显式建模。本文首次提出将 HypHC（Chami et al., NeurIPS 2020）的连续层级聚类机制从点云内部的**点级结构**迁移至跨样本的**实例级结构**，在同一庞加莱球上同时保留 intra 并新增 inter，实现完整的双层层级几何。

### 1.2 框架演进路径

| 版本 | 关键修正 | 触发原因 |
|---|---|---|
| v1.0 | 加权 Gromov 积 margin 三元组 $L_{\text{inter}}$ | 初始设计 |
| v1.1 | 取消 whole 嵌入的固定半径约束，改为仅要求 $\|z_{\text{part}}\| < \|z_{\text{whole}}\|$ | 固定半径与 Gromov 积互斥 |
| v2.0 | 引入类内 HypHC softmax 三元组 $L_{\text{intra-class}}$ | margin 三元组无法保序 |
| **v2.1** | 保留跨类 margin 作为安全网（$\beta_{\text{inter}}$ 极小）+ HyCoRe 预训练 + 周期性重算 $w_{ij}$ | 稳定性和信号质量 |

## 二、总损失函数

$$L_{\text{total}} = L_{\text{task}} + \alpha \cdot L_{\text{intra}} + \beta_{\text{ic}} \cdot L_{\text{intra-class}} + \beta_{\text{inter}} \cdot L_{\text{inter}}$$

| 损失项 | 形式 | 语义角色 | 权重 |
|---|---|---|---|
| $L_{\text{task}}$ | 分类：交叉熵；分割：逐点交叉熵 | 主任务判别 | 全程激活 |
| $L_{\text{intra}}$ | HyCoRe 的 $R_{\text{hier}}$（v1.1）+ $R_{\text{contr}}$ | 单样本内 part-whole 层级 | 全程激活 |
| $L_{\text{intra-class}}$ | HypHC softmax 三元组（类内） | **类内多层树结构塑形（核心贡献）** | warm-up 后激活 |
| $L_{\text{inter}}$ | 加权 Gromov 积 margin 三元组（跨类） | 跨类方向锥分离底线守护 | warm-up 后激活（$\beta_{\text{inter}}$ 极小） |

## 三、三大损失项的详细设计

### 3.1 $L_{\text{intra}}$：Intra-Sample Part-Whole 层级（复用 HyCoRe，v1.1 修正）

**$R_{\text{hier}}$（v1.1 修正版）**

$$R_{\text{hier}} = \max(0,\; \|z_{\text{part}}\| - r_{\text{part}}) + \max(0,\; \|z_{\text{part}}\| - \|z_{\text{whole}}\| + \delta)$$

- **第一项**：约束 part 嵌入的绝对范数不超过 $r_{\text{part}}$，保证 part 在球心附近（通用/抽象区域）
- **第二项**：约束 part 范数严格小于 whole 范数（留 $\delta = 0.1$ 间距），保留 part-whole 的方向性层级语义
- **修正要点**：**不再约束 whole 嵌入的绝对范数**，whole 的径向位置交由 $L_{\text{intra-class}}$ 和 $L_{\text{task}}$ 自由决定

**$R_{\text{contr}}$（原样保留）**

$$R_{\text{contr}} = \max\left(0,\; d(z_{\text{whole}}^i, z_{\text{part}}^i) - d(z_{\text{whole}}^i, z_{\text{part}}^j) + \delta\right)$$

- $z_{\text{whole}}^i$ 和 $z_{\text{part}}^i$ 为同一样本的 whole 和 part 嵌入（正例对）
- $z_{\text{part}}^j$ 为不同样本的 part 嵌入（负例）
- 语义：同一样本的 whole-part 方向应当一致，防止嵌入塌缩

### 3.2 $L_{\text{intra-class}}$：类内多层树结构塑形（★ 核心贡献）

这是框架 v2.1 的核心创新：将 HypHC 的连续层级聚类从"单点云内部的点对"升级为"同类多个样本的 whole 嵌入对"。

#### 3.2.1 数学形式

$$L_{\text{intra-class}} = \sum_{c \in \mathcal{C}_{\text{batch}}} \sum_{i,j,k \in \mathcal{S}_c} \left[(w_{ij}+w_{ik}+w_{jk}) - (w_{ij},w_{ik},w_{jk}) \cdot \sigma_\tau\left((z_i|z_j)_0, (z_i|z_k)_0, (z_j|z_k)_0\right)^\top\right]$$

其中：
- $\mathcal{C}_{\text{batch}}$：当前 batch 中被选中的类别（每 batch 随机选 4-5 类）
- $\mathcal{S}_c$：类别 $c$ 在当前 batch 中的样本集合（每类 5-8 个）
- $(z_i|z_j)_0 = \frac{d(z_i,0)+d(z_j,0)-d(z_i,z_j)}{2}$：**Gromov 积**，即双曲 LCA 到原点的距离
- $\sigma_\tau$：温度为 $\tau$ 的 softmax
- $w_{ij}$：stop-gradient 的余弦相似度（见§3.4）

#### 3.2.2 损失语义——为什么能形成类内子树

HypHC softmax 在三元组 $(i,j,k)$ 的三个 Gromov 积之间做**概率竞争**。$(w_{ij}, w_{ik}, w_{jk})$ 作为权重向量，决定了"哪对应该先合并（LCA 最深）"：

- 当 $w_{ij} > w_{ik} > w_{jk}$ 时，softmax 被激励在 $(z_i|z_j)_0$ 上分配最大概率 → 优化器将 $(z_i|z_j)_0$ 推至最大
- 连续权重差产生连续 Gromov 积差 → 形成**真正的多层树形层级**：

```
折叠椅A ←→ 折叠椅B        LCA最深（w_AB最大）
    ↘    ↙
     折叠椅组 ←→ 办公椅C    LCA居中（w_AC居中）
         ↘    ↙
          椅子全体             LCA比跨类更深
```

关键性质：**$w_{ij}$ 的排序通过 softmax 竞争被显式转化为 Gromov 积的排序**——这不是涌现，是硬约束。

#### 3.2.3 三元组构造与 batch 采样策略

**核心约束**：softmax 需要每个类别 ≥ 3 个样本才能构造三元组，≥ 5 个样本才能有足够丰富的排序空间。

**采样策略**：

- 每 batch 随机选取 4-5 个类别
- 每类采样 5-8 个样本
- Batch size ≈ 32-40（可控）
- Class-balanced sampling：确保每类都有代表

**三元组枚举**：选中类别 $c$ 的 $n_c$ 个样本中，枚举所有 $\binom{n_c}{3}$ 个三元组，对每个三元组计算 HypHC softmax 损失。

### 3.3 $L_{\text{inter}}$：跨类分离底线守护（保留，权重极小）

$$L_{\text{inter}} = \frac{1}{|\mathcal{T}|}\sum_{(i,j,k) \in \mathcal{T}} \max\left(0,\; (z_i|z_k)_0 - (z_i|z_j)_0 + m\right)$$

- $(i,j)$：同类的两个 whole 嵌入，$k$：异类 whole 嵌入
- $m$：margin（推荐 0.1-0.2）
- $\beta_{\text{inter}}$ 设为极小值（0.005-0.01）

**角色定位**：不作为主动塑形力，而是"沉睡的安全网"。在正常训练中梯度几乎为零（各类方向锥已自然分离），只在类别方向锥意外靠近时被唤醒，防止类内层级被跨类混淆稀释。

### 3.4 $w_{ij}$ 的获取策略：HyCoRe 预训练 + 周期性重算

$$w_{ij} = \text{cosine\_similarity}\left(\text{detach}(z_i^{\text{whole}}),\; \text{detach}(z_j^{\text{whole}})\right)$$

#### 3.4.1 为什么用 stop-gradient

$w_{ij}$ 不直接接收 $L_{\text{intra-class}}$ 的梯度，避免"损失函数用自己的输出监督自己"的自举不稳定回路。

#### 3.4.2 为什么用 HyCoRe 预训练

HyCoRe 预训练已在双曲空间里建立了有意义的特征分布：part 靠球心、whole 靠球边缘、同类样本在方向锥内有散布（不强制对齐）。这个散布方差就是你需要的 $w_{ij}$ 差异来源。

预训练阶段使用原始的固定半径 $R_{\text{hier}}$（而非 v1.1 修正版），因为此时还没有 inter 约束，固定半径可以提供稳定的初始几何结构。

#### 3.4.3 训练流程

```
═══════════════════════════════════════════════
阶段零：HyCoRe 预训练（标准设定）
═══════════════════════════════════════════════
L = L_task + α · (R_hier + R_contr)
R_hier 使用原始固定半径版本
训练至收敛，保存权重 checkpoint

═══════════════════════════════════════════════
阶段一：v1.1 适配（前 10-15 epoch）
═══════════════════════════════════════════════
L = L_task + α · (R_hier_v1.1 + R_contr)
R_hier 切换为 v1.1 修正版（取消 whole 固定半径）
β_ic = 0, β_inter = 0（inter 损失暂不激活）
目标：让 whole 嵌入在自由范数设定下重新调整，
      建立适合 inter 约束的初始特征空间

═══════════════════════════════════════════════
阶段二：计算初始 w_ij + 激活 inter
═══════════════════════════════════════════════
用阶段一末的编码器，stop-gradient 计算全部训练样本的 w_ij
将 w_ij 存入相似度查找表

激活 L_intra-class 和 L_inter（β_inter 极小）
β_ic 从 0 线性增大至目标值（10-15 epoch warm-up）

═══════════════════════════════════════════════
阶段三：周期性重算 w_ij
═══════════════════════════════════════════════
每 K 个 epoch（推荐 K=5），用当前编码器重新计算全部 w_ij
同时监控 w_ij 排名的 Kendall τ 系数：
  - 若 τ 稳定（连续 3 次重算间变化 < 0.05），增大 K
  - 若 τ 剧烈变化（> 0.15），减小 K 或暂停重算
继续训练至收敛
═══════════════════════════════════════════════
```

## 四、网络架构

### 4.1 分类任务（ModelNet40 / ScanObjectNN）

```
输入点云 x (N×3)
       │
       ▼
  编码器主干（PointMLP / PointNeXt / DGCNN）
       │
       ▼
  Global Max Pooling → 欧式全局特征 g (1×F)
       │
       ▼
  exp map → whole 嵌入 z_whole ∈ B^F
       │
       ├──→ 分类头（Möbius 层 + softmax）→ 类别预测 → L_task
       │
       └──→ L_intra（part 嵌入来自中间层 kNN 聚合）
            L_intra-class（同类 whole 嵌入间的 HypHC softmax）
            L_inter（跨类 margin 三元组）
```

### 4.2 分割任务（ShapeNetPart，双分支设计）

```
输入点云 x (N×3)
       │
       ▼
  编码器主干（PointNeXt / DGCNN，共享参数）
       │
       ├──────────────────────────┐
       ▼                          ▼
  逐点特征 Z (N×F)           Global Max Pooling
       │                          │
       ▼                          ▼
  exp map                     exp map
       │                          │
       ▼                          ▼
  逐点双曲嵌入 Z_pt           whole 嵌入 z_whole
       │                          │
       ▼                          │
  分割头（Möbius 层）          L_intra-class（同类样本间）
       │                      L_inter（跨类安全网）
       ▼
  逐点类别预测 → L_task
       │
       ▼
  L_intra（R_hier + R_contr）
```

**双分支设计原理**：

- 逐点分支接受 $L_{\text{task}} + L_{\text{intra}}$ 的梯度，保证分割精度和 part-whole 层级
- 全局分支只接受 $L_{\text{intra-class}} + L_{\text{inter}}$ 的梯度，避免 inter 梯度通过 global pooling 扰动逐点嵌入
- 两者共享编码器主干参数，inter 的梯度通过主干间接影响整体表示学习

## 五、庞加莱球几何布局

### 5.1 Intra + Inter 共存的空间结构

```
                    ╔══════════════════════════════╗
                    ║      庞加莱球 B^N           ║
                    ║                              ║
  球边缘（特化）    ║  ┌─────────────────────────┐ ║
        ↑           ║  │ 椅子方向锥：              │ ║
        │           ║  │   折叠椅A 折叠椅B  ←  LCA最深（靠外）
        │           ║  │      \      /              │ ║
        │           ║  │       折叠椅组LCA          │ ║
        │           ║  │          \                 │ ║
        │           ║  │          办公椅C           │ ║
        │           ║  │            \    椅子方向锥 │ ║
        │           ║  └─────────────┬───────────────┘ ║
        │           ║                │                  ║
        │           ║  ┌─────────────┼───────────────┐ ║
        │           ║  │ 桌子方向锥  │               │ ║
        │           ║  │   桌子D 桌子E 桌子F         │ ║
        │           ║  └─────────────┘               │ ║
        │           ║                              ║
        │           ║  part 嵌入散布在球心附近       ║
        │           ║  （圆柱、平面等通用几何原语）  ║
  球心（通用）      ╚══════════════════════════════╝
```

### 5.2 关键几何关系

| 关系 | 几何表达 | 约束来源 |
|---|---|---|
| Part < Whole（单样本内） | $\|z_{\text{part}}\| < \|z_{\text{whole}}\|$ | $R_{\text{hier}}$（v1.1） |
| Whole-Part 方向一致 | $d(z_{\text{whole}}, z_{\text{part}}) < d(z_{\text{whole}}, z_{\text{part}}')$ | $R_{\text{contr}}$ |
| 同类相似实例 LCA 更深 | $(z_{\text{foldA}}\|z_{\text{foldB}})_0 > (z_{\text{foldA}}\|z_{\text{officeC}})_0$ | $L_{\text{intra-class}}$（softmax 保序） |
| 同类 LCA > 跨类 LCA | $(z_{\text{chair}}\|z_{\text{chair}})_0 > (z_{\text{chair}}\|z_{\text{table}})_0$ | $L_{\text{inter}}$（安全网） + $L_{\text{task}}$（隐式） |

## 六、超参数设定

| 超参数 | 含义 | 推荐范围 | 初始值 |
|---|---|---|---|
| $\alpha$ | $L_{\text{intra}}$ 权重 | 0.01~0.1 | 0.01 |
| $\beta_{\text{ic}}$ | $L_{\text{intra-class}}$ 权重 | 0.01~0.1 | 从 0 线性 warm-up 至 0.05 |
| $\beta_{\text{inter}}$ | $L_{\text{inter}}$ 权重 | 0.001~0.01 | 0.005（极小安全网） |
| $\tau$ | HypHC softmax 温度 | 0.05~0.5 | 0.1（HPCS 原值） |
| $r_{\text{part}}$ | part 嵌入最大范数 | 0.3~0.6 | 0.5 |
| $\delta$ | intra margin | 0.05~0.2 | 0.1 |
| $m$ | inter margin | 0.1~0.3 | 0.15 |
| $c$ | 庞加莱球曲率 | 0.01~1.0 | 1.0（初始），可选可学习曲率 |
| $K$ | $w_{ij}$ 重算周期 | 3~10 epoch | 5 |
| batch size | 每 batch 样本数 | 32~64 | 40（4 类 × 8 样本 + 4 类 × 2 样本） |

## 七、实验验证设计

### 7.1 基础消融

| 配置 | 激活项 | 验证目标 |
|---|---|---|
| Baseline | $L_{\text{task}}$ only | 基准性能 |
| +Intra | $L_{\text{task}} + L_{\text{intra}}$ | HyCoRe 效果复现 |
| +Inter (margin) | $L_{\text{task}} + L_{\text{intra}} + L_{\text{inter}}$ | 仅跨类 margin 的效果 |
| +Intra-class | $L_{\text{task}} + L_{\text{intra}} + L_{\text{intra-class}}$ | 仅类内 softmax 的效果 |
| Full v2.1 | $L_{\text{task}} + L_{\text{intra}} + L_{\text{intra-class}} + L_{\text{inter}}$ | 完整框架 |

### 7.2 诊断性实验

| 诊断问题 | 实验方案 |
|---|---|
| 类内层级是否形成？ | 对椅子类别计算所有同类 sample pair 的 Gromov 积，与 $w_{ij}$ 做 Spearman 相关性分析 |
| 类内 vs 跨类 Gromov 积分是否分离？ | 画同类对和跨类对的 Gromov 积分布直方图/箱线图 |
| 两个尺度是否冲突？ | 监控 $\|\nabla L_{\text{intra}}\| / \|\nabla L_{\text{intra-class}}\|$ 比值 |
| $w_{ij}$ 是否稳定？ | 监控重算时 $w_{ij}$ 排名的 Kendall $\tau$ 相关系数 |
| 曲率的影响？ | $c \in \{0.01, 0.1, 0.5, 1.0\}$ 消融 |
| 温度 $\tau$ 的影响？ | $\tau \in \{0.05, 0.1, 0.2, 0.5\}$，监控 softmax 熵和类内 Gromov 积梯度 |

### 7.3 可视化验证

- **UMAP**：对椅子类别测试样本的 whole 嵌入做降维可视化，观察是否出现折叠椅/办公椅的亚类聚集
- **双曲球 2D 投影**：在庞加莱盘上同时绘制同类样本的 whole 嵌入和 inter LCA 位置
- **Gromov 积矩阵热力图**：对 10 类 × 每类 10 样本，绘制 100×100 的 Gromov 积矩阵，观察块对角结构

## 八、贡献叙事

> 本文首次在点云双曲框架里显式建模 inter-sample hierarchy。我们将 HypHC 的连续层级聚类机制从单点云内部的点级结构迁移至跨样本的实例级结构，提出类内 HypHC softmax 三元组损失——利用编码器特征的余弦相似度作为连续权重，在同类样本间构造由几何亲疏度驱动的软性树形层级。与现有工作仅在单样本内部利用双曲空间不同，本框架在同一庞加莱球上同时保留了 intra-sample 的 part-whole 层级（复用 HyCoRe 并取消 whole 嵌入的固定半径约束）并新增了 inter-sample 的实例级层级。这是首个将 HypHC 的层级聚类能力从"单样本内"扩展到"多样本间"的工作。

## 九、已知局限

| 局限 | 描述 | 应对 |
|---|---|---|
| 类内三元组降低 batch 多样性 | 每 batch 只选 4-5 类，不同 batch 优化不同类别 | 无偏估计（期望），但方差增大 |
| 类间没有多层树结构 | 跨类对之间不做 softmax 竞争，不能区分"相近的跨类"和"无关的跨类" | 留作后续工作；$L_{\text{task}}$ 隐式提供跨类分离 |
| $w_{ij}$ 来自自举回路 | 周期性重算不能完全消除自举延迟 | 监控 Kendall $\tau$ 稳定性，必要时升级至动量编码器 |
| 预训练依赖性 | 框架依赖 HyCoRe 预训练提供初始特征分布 | 基线实验需包含"随机初始化 + warmup"对比 |
